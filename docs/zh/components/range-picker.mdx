选择开始与结束日期，并可包含时间和快捷预设。

## 何时使用

筛选、报表或预订流程需要明确时间范围时使用 RangePicker。

**推荐**

- 提供常用范围预设。
- 清晰表达开始与结束顺序。

**避免**

- 只选单日时不要使用 RangePicker。

## 基础用法

```tsx preview
import { FormField, RangePicker } from '@rockshin/tao-ui';

function RangePickerExample() {
  return (
    <FormField label="Reporting period">
      <RangePicker />
    </FormField>
  );
}

export default RangePickerExample;
```

## 受控日期范围

```tsx preview
import { RangePicker } from '@rockshin/tao-ui';
import dayjs from 'dayjs';
import { useState } from 'react';

function ControlledRangePicker() {
  const [value, setValue] = useState([dayjs().startOf('week'), dayjs().endOf('week')]);

  return <RangePicker value={value} onChange={setValue} />;
}

export default ControlledRangePicker;
```

## 预设与时间

```tsx preview
import { RangePicker, Stack } from '@rockshin/tao-ui';
import dayjs from 'dayjs';

function RangePickerPresets() {
  return (
    <Stack gap="md">
      <RangePicker
        presets={[
          { label: 'This week', value: [dayjs().startOf('week'), dayjs().endOf('week')] },
          { label: 'This month', value: [dayjs().startOf('month'), dayjs().endOf('month')] },
        ]}
      />
      <RangePicker showTime />
    </Stack>
  );
}

export default RangePickerPresets;
```
