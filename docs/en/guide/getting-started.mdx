## Add the provider

Wrap your application once with `TaoProvider`. Components inherit settings such as size, disabled state, and theme mode.

```tsx
import { Button, TaoProvider } from '@rockshin/tao-ui';

export default function App() {
  return (
    <TaoProvider size="medium">
      <Button>Continue</Button>
    </TaoProvider>
  );
}
```

## Use dark mode

Set the theme mode on the provider. Portaled components inherit the same theme.

```tsx
<TaoProvider theme={{ mode: 'dark' }}>
  <App />
</TaoProvider>
```
