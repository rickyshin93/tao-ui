Displays structured row and column data with selection, sorting, filtering, and pagination hooks.

## When to use

Use Table for dense, comparable records that benefit from aligned columns.

**Recommended**

- Keep columns focused on the task.
- Use stable row keys.
- Control sorting and pagination when data is remote.
- Gate secondary columns with column.responsive (e.g. ['lg']) instead of hand-rolled media queries.

**Avoid**

- Do not use Table for card-like content where comparison is not important.

## Basic usage

```tsx preview
import { Table } from '@rockshin/tao-ui';

const columns = [
  { key: 'name', dataIndex: 'name', title: 'Name' },
  { key: 'role', dataIndex: 'role', title: 'Role' },
];

const users = [
  { id: 1, name: 'Ada Lovelace', role: 'Engineer' },
  { id: 2, name: 'Grace Hopper', role: 'Scientist' },
];

function TableExample() {
  return <Table columns={columns} dataSource={users} rowKey="id" pagination={false} />;
}

export default TableExample;
```

## Variants

```tsx preview
import { Stack, Table } from '@rockshin/tao-ui';

const columns = [
  { key: 'name', dataIndex: 'name', title: 'Name' },
  { key: 'role', dataIndex: 'role', title: 'Role' },
];

const data = [
  { id: 1, name: 'Ada', role: 'Engineer' },
  { id: 2, name: 'Grace', role: 'Scientist' },

  return (

      <Table columns={columns} dataSource={data} rowKey="id" variant="modern" pagination={false} />
      <Table columns={columns} dataSource={data} rowKey="id" variant="borderless" pagination={false} />
    </Stack>
  );
}

export default TableVariants;
```

## Loading, empty, and pagination

```tsx preview
import { Stack, Table } from '@rockshin/tao-ui';

const columns = [{ key: 'name', dataIndex: 'name', title: 'Name' }];

function TableStates() {
  return (
    <Stack gap="lg">
      <Table loading columns={columns} dataSource={[]} rowKey="id" />
      <Table
        columns={columns}
        dataSource={[]}
        rowKey="id"
        emptyText="No matching users."
        pagination={false}
      />
      <Table
        columns={columns}
        dataSource={Array.from({ length: 12 }, (_, index) => ({ id: index, name: 'User ' + (index + 1) }))}
        rowKey="id"
        pagination={{ pageSize: 5 }}
      />
    </Stack>
  );
}

export default TableStates;
```

## Fixed header, expandable rows, and summary

`scroll.y` caps the body height and pins the header; `expandable` renders details under a row (the expand column sits before the selection column); `summary` returns `Table.Summary.Row` / `Table.Summary.Cell` footer rows — `Cell.index` counts from the expand/selection columns to sync fixed columns, and `<Table.Summary fixed>` pins the footer while the body scrolls.

```tsx preview
import { Table } from '@rockshin/tao-ui';

const data = Array.from({ length: 30 }, (_, index) => ({
  id: index + 1,
  name: 'User ' + (index + 1),
  team: ['Design', 'Engineering', 'Sales'][index % 3],
  score: 60 + ((index * 7) % 40),
}));

const columns = [
  { key: 'name', dataIndex: 'name', title: 'Name', width: 160, fixed: 'left' },
  { key: 'team', dataIndex: 'team', title: 'Team', width: 240 },
  { key: 'score', dataIndex: 'score', title: 'Score', width: 120, align: 'right' },
];

function TableAdvanced() {
  return (
    <Table
      columns={columns}
      dataSource={data}
      rowKey="id"
      pagination={false}
      scroll={{ x: 640, y: 280 }}
      expandable={{
        expandedRowRender: (record) => record.name + ' works in ' + record.team + '.',
        rowExpandable: (record) => record.team !== 'Sales',
      }}
      summary={(pageData) => (
        <Table.Summary fixed>
          <Table.Summary.Row>
            <Table.Summary.Cell index={0} colSpan={3}>Total</Table.Summary.Cell>
            <Table.Summary.Cell index={3} align="right">
              {pageData.reduce((sum, record) => sum + record.score, 0)}
            </Table.Summary.Cell>
          </Table.Summary.Row>
        </Table.Summary>
      )}
    />
  );
}

export default TableAdvanced;
```
