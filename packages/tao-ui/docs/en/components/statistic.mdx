Highlights numeric values, formatted metrics and elapsed time.

This native tao-ui component follows the public API of Ant Design 6.7.0. Appearance, theme tokens and Semantic DOM customization belong to tao-ui; configure themes with `TaoProvider`.

Numeric strings preserve large values; precision truncates decimal digits. Timer supports countdown/countup and the legacy Countdown alias.

## When to use

Use a clear title and unit so the value can be understood without surrounding context.

### Custom formatting and value render

```tsx preview

export default function Example() {
  return (
    <Statistic
      title="Storage used"
      value={1536}
      formatter={(value) => `${(Number(value) / 1024).toFixed(1)} GB`}
      valueRender={(node) => <strong>{node}</strong>}
      styles={{ value: { color: "var(--tao-color-success)" } }}
```

### Countdown with completion

```tsx preview
import { useState } from "react";
import { Button, Statistic } from "@rockshin/tao-ui";

export default function Example() {
  const [deadline, setDeadline] = useState(() => Date.now() + 10000);
  const [finished, setFinished] = useState(false);
  return (
    <div>
      <Statistic.Timer
        type="countdown"
        title="Time remaining"
        value={deadline}
        format="mm:ss"
        onFinish={() => setFinished(true)}
      />
      <p aria-live="polite">{finished ? "Finished" : "Running"}</p>
      <Button
        onClick={() => {
          setDeadline(Date.now() + 10000);
          setFinished(false);
        }}
      >
        Restart 10 seconds
      </Button>
    </div>
  );
}
```

</section>

```tsx preview
import { useState } from "react";

export default function Example() {
```
