Lays out submit, cancel, and secondary actions for forms.

## When to use

Use FormActions at the end of a form or section to align the final actions consistently.

**Recommended**

- Keep action order consistent across forms.
- Use a single submit action unless the workflow truly branches.

**Avoid**

- Do not use the component outside its intended interaction model.

### Complete form composition

Compose layout, fields, and actions with native submission feedback.

```tsx preview
import { useState } from 'react';
import {
  FormLayout,
  FormSection,
  FormField,
  FormActions,
  Input,
  Textarea,
  Button,
} from '@rockshin/tao-ui';
export default function Example() {
  const [saved, setSaved] = useState('');
  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        setSaved(String(new FormData(e.currentTarget).get('name')));
      }}
      onReset={() => setSaved('')}
    >
      <FormLayout>
        <FormSection title="Profile" description="Public workspace information">
          <FormField label="Display name" required>
            <Input name="name" required defaultValue="Alex" />
          </FormField>
          <FormField label="Bio" description="A short introduction">
            <Textarea name="bio" autoSize />
          </FormField>
        </FormSection>
        <FormActions>
          <Button type="reset">Reset</Button>
          <Button type="submit" variant="primary">
            Save
          </Button>
        </FormActions>
        <output aria-live="polite">
          {saved ? `Saved ${saved}` : 'No changes saved'}
        </output>
      </FormLayout>
    </form>
  );
}
```

</section>

### Alignment and wrapping

import { FormActions, Button } from '@rockshin/tao-ui';

  return (

### Pending actions

Disable form actions while pending and show loading; a separate control finishes this local demo.

```tsx preview
import { useState } from 'react';
import { FormActions, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [pending, setPending] = useState(false);
  return (
    <Stack direction="vertical">
      <FormActions>
        <Button disabled={pending}>Cancel</Button>
        <Button loading={pending} onClick={() => setPending(true)}>
          Save
        </Button>
      </FormActions>
      {pending && (
        <Button onClick={() => setPending(false)}>
          Finish simulated request
        </Button>
      )}
    </Stack>
  );
}
```
