Composes children in a flex row or column with consistent spacing.

## When to use

Use Stack for simple one-dimensional layout and spacing.

**Recommended**

- Prefer Stack over one-off margin rules for repeated spacing.
- Use semantic containers when the layout has richer meaning.
- Pass breakpoint maps (for example, `direction={{ xs: 'vertical', md: 'horizontal' }}`) for responsive layouts.

**Avoid**

- Do not use the component outside its intended interaction model.

### Basic usage

```tsx preview
import { Stack, Tag } from '@rockshin/tao-ui';

function StackExample() {
  return (
    <Stack direction="horizontal" gap="md" align="center">
      <Tag>Design</Tag>

      <Tag>Research</Tag>
    </Stack>
  );
}

export default StackExample;
```

### Responsive direction

```tsx preview
import { Button, Stack } from '@rockshin/tao-ui';

function ResponsiveStack() {
  return (
    <Stack
      direction={{ xs: 'vertical', md: 'horizontal' }}
      gap={{ xs: 'sm', md: 'lg' }}
    >
      <Button>Save</Button>
      <Button variant="secondary">Preview</Button>
      <Button variant="ghost">Cancel</Button>
    </Stack>
  );
}

export default ResponsiveStack;
```

### Alignment

Use align and justifyContent on the root to position children.

```tsx preview
import { Stack, Button } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Stack
      align="center"
      styles={{
        root: {
          justifyContent: 'space-between',
          minHeight: 100,
          width: '100%',
        },
      }}
    >
      <Button>Start</Button>
      <span>Centered vertically</span>
      <Button>End</Button>
    </Stack>
  );
}
```

</section>

### Wrapping items

Enable flexWrap on the semantic root so a long toolbar can wrap.

```tsx preview
import { Stack, Button } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Stack styles={{ root: { flexWrap: 'wrap' } }}>
      {['Overview', 'Members', 'Permissions', 'Billing', 'Settings'].map(
        (item) => (
          <Button key={item}>{item}</Button>
        ),
      )}
    </Stack>
  );
}
```

</section>

### Responsive direction and gap

Use a vertical arrangement in narrow viewports and horizontal at wider breakpoints. Compare the phone preview.

```tsx preview="iframe-follow"
import { Stack, Input, Button } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Stack
      direction={{ xs: 'vertical', md: 'horizontal' }}
      gap={{ xs: 'sm', md: 'lg' }}
      align="stretch"
    >
      <Input aria-label="Email address" placeholder="name@example.com" />
      <Button variant="primary">Continue</Button>
    </Stack>
  );
}
```

</section>

### Nested layouts

Let the outer stack space sections and the inner stack group related actions.

```tsx preview
import { Stack, Button } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Stack direction="vertical" gap="lg">
      <div>
        <strong>Workspace</strong>
        <p>Invite members and manage access.</p>
      </div>
      <Stack styles={{ root: { flexWrap: 'wrap' } }}>
        <Button variant="primary">Invite member</Button>
        <Button>Manage roles</Button>
      </Stack>
    </Stack>
  );
}
```
