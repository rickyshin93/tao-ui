Displays a floating card with rich content anchored to a trigger element, opened by click or hover.

## When to use

Use Popover for rich, non-blocking contextual content behind a click or hover. Use Tooltip for short text-only hints and Modal for blocking interactions.

**Recommended**

- Keep the title to one short line; put detail in the content.
- Use the default hover trigger for read-only previews and trigger="click" for interactive content.
- Keep popup content compact; link out for long-form detail.

**Avoid**

- Do not nest essential workflows inside a hover-only popover.
- Do not chain popovers from inside another popover.

### Basic usage

```tsx preview
import { Button, Popover } from '@rockshin/tao-ui';

function PopoverExample() {
  return (
    <Popover
      trigger="click"
      title="Deployment"
      content="Production was updated 2 minutes ago."
    >
      <Button variant="secondary">View status</Button>
    </Popover>
  );
}

export default PopoverExample;
```

### Controlled popup and internal dismissal

An action inside the popup can update open and dismiss it after completion.

```tsx preview
import { useState } from 'react';
import { Popover, Button } from '@rockshin/tao-ui';
export default function Example() {
  const [open, setOpen] = useState(false);
  return (
    <Popover
      trigger="click"
      title="Quick action"
      open={open}
      onOpenChange={setOpen}
      content={<Button onClick={() => setOpen(false)}>Done</Button>}
    >
      <Button>Open actions</Button>
    </Popover>
  );
}
```

### Focus trigger

Use trigger=focus for keyboard hints and keep essential instructions visible on the page.

```tsx preview
import { Popover, Input } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Popover
      trigger="focus"
      title="Project code"
      content="Use a short, recognizable identifier."
    >
      <Input aria-label="Project code" placeholder="Focus this input" />
    </Popover>
  );
}
```

### Arrow and delay

Hover delays use seconds, and arrow controls the pointer.

```tsx preview
import { Popover, Button } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Popover
      title="Details"
      content="Additional context appears after a short delay."
      arrow={false}
      mouseEnterDelay={0.4}
      mouseLeaveDelay={0.2}
    >
      <Button>Hover for details</Button>
    </Popover>
  );
}
```

### Form content

A popup can contain input and actions; submit, report the result, and close it.

```tsx preview
import { useState } from 'react';
import { Popover, Input, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [open, setOpen] = useState(false);
  const [name, setName] = useState('Workspace');
  return (
    <Stack direction="vertical">
      <Popover
        trigger="click"
        open={open}
        onOpenChange={setOpen}
        title="Rename"
        content={
          <form
            onSubmit={(e) => {
              e.preventDefault();
              setName(String(new FormData(e.currentTarget).get('name')));
              setOpen(false);
            }}
          >
            <Stack direction="vertical">
              <Input
                name="name"
                aria-label="New name"
                defaultValue={name}
                required
              />
              <Button type="submit">Save name</Button>
            </Stack>
          </form>
        }
      >
        <Button>Rename project</Button>
      </Popover>
      <output>{name}</output>
    </Stack>
  );
}
```
