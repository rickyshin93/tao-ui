Shows a brief informational popup when hovering or focusing an element.

## When to use

Use Tooltip for short contextual hints on hover or focus. The popup is portaled and inherits the TaoProvider theme.

**Recommended**

- Keep tooltip text short and supplementary.
- Wrap exactly one focusable trigger element.

**Avoid**

- Do not put critical information or interactive content inside a Tooltip.

### Controlled tooltip

Synchronize visibility through open and onOpenChange.

```tsx preview
import { useState } from 'react';
import { Button, Stack, Tooltip } from '@rockshin/tao-ui';
export default function Example() {
  const [open, setOpen] = useState(false);
  return (
    <Stack direction="horizontal">
      <Button onClick={() => setOpen(!open)}>
        {open ? 'Hide hint' : 'Show hint'}
      </Button>
      <Tooltip open={open} onOpenChange={setOpen} title="Controlled hint">
        <Button>Hint target</Button>
      </Tooltip>
    </Stack>
  );
}
```

### Hover delays

Delays use seconds; keyboard focus does not wait for a hover delay.

```tsx preview
import { Tooltip, Button } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Tooltip
      title="Wait 0.6 seconds on hover"
      mouseEnterDelay={0.6}
      mouseLeaveDelay={0.2}
    >
      <Button>Hover or focus</Button>
    </Tooltip>
  );
}
```

</section>

### Conditional content

An empty title disables the tooltip so hints only appear when useful.

```tsx preview
import { useState } from 'react';
import { Tooltip, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [enabled, setEnabled] = useState(true);
  return (
    <Stack direction="vertical">
      <Button onClick={() => setEnabled(!enabled)}>
        {enabled ? 'Disable hint' : 'Enable hint'}
      </Button>
      <Tooltip title={enabled ? 'Additional information' : null}>
        <Button>Hint target</Button>
      </Tooltip>
    </Stack>
  );
}
```
