Toggles a setting on or off with immediate effect.

## When to use

Use Switch for settings that take effect immediately.

**Recommended**

- Use labels that describe the enabled state.
- Use Checkbox when the value is submitted with a form.

**Avoid**

- Do not use the component outside its intended interaction model.

### Basic usage

```tsx preview
import { Stack, Switch } from '@rockshin/tao-ui';
import { useState } from 'react';

function SwitchExample() {
  const [enabled, setEnabled] = useState(true);

  return (
    <Stack direction="horizontal" gap="lg" align="center">
      <Switch checked={enabled} onChange={setEnabled} />
      <Switch checked loading />
      <Switch disabled />
    </Stack>
  );
}

export default SwitchExample;
```

### Controlled switch

onChange returns a boolean that can directly update setting state.

```tsx preview
import { useState } from 'react';
import { Switch, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [enabled, setEnabled] = useState(true);
  return (
    <Stack direction="vertical">
      <Switch
        aria-label="Notifications"
        checked={enabled}
        onChange={setEnabled}
      />
      <output>
        {enabled ? 'Notifications enabled' : 'Notifications disabled'}
      </output>
    </Stack>
  );
}
```

### Loading prevents repeated toggles

Use a separate button to toggle loading and inspect the waiting state.

```tsx preview
import { useState } from 'react';
import { Switch, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [loading, setLoading] = useState(false);
  return (
    <Stack direction="vertical">
      <Switch aria-label="Sync" loading={loading} defaultChecked />
      <Button onClick={() => setLoading(!loading)}>
        {loading ? 'Finish loading' : 'Start loading'}
      </Button>
    </Stack>
  );
}
```

</section>

### Shared size and disabled state

Multiple switches inherit configuration; a local disabled prop can override it.

```tsx preview
import { Switch, TaoProvider, Stack } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <TaoProvider size="small" disabled>
      <Stack>
        <Switch aria-label="Inherited disabled" defaultChecked />
        <Switch aria-label="Enabled override" disabled={false} />
      </Stack>
    </TaoProvider>
  );
}
```
