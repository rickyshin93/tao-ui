Select, drop and manage files with real requests, custom uploads and controlled lists.

The added API follows Ant Design 6.7.0; appearance, theming and Semantic DOM use tao-ui. Existing component APIs remain unchanged.

### Select without uploading

This example keeps files locally. Returning false from beforeUpload prevents requests.

```tsx preview
import { Upload, Button } from '@rockshin/tao-ui';
export default function Demo() {
  return (
    <Upload beforeUpload={() => false}>
      <Button>Select document</Button>
    </Upload>
  );
}
```

### Controlled file list

Own fileList through onChange; the clear button updates the same state.

```tsx preview
import { Upload, Button, Stack, type UploadFile } from '@rockshin/tao-ui';
import { useState } from 'react';
export default function Demo() {
  const [files, setFiles] = useState<UploadFile[]>([]);
  return (
    <Stack gap="md">
      <Upload
        fileList={files}
        beforeUpload={() => false}
        onChange={(info) => setFiles(info.fileList)}
      >
        <Button>Select files</Button>
      </Upload>
      <Button variant="secondary" onClick={() => setFiles([])}>
        Clear list
      </Button>
    </Stack>
  );
}
```

</section>

### Validate and ignore files

LIST_IGNORE excludes rejected files from the list. Browser accept is only a selection hint.

```tsx preview
import { Upload, Button } from '@rockshin/tao-ui';
import { useState } from 'react';
export default function Demo() {
  const [error, setError] = useState('');
  return (
    <div>
      <Upload
        accept="image/*"
        beforeUpload={(file) => {
          if (!file.type.startsWith('image/')) {
            setError('Choose an image file.');
            return Upload.LIST_IGNORE;
          }
          setError('');
          return false;
        }}
      >
        <Button>Select image</Button>
      </Upload>
      <p role="status">{error}</p>
    </div>
  );
}
```

</section>

### Multiple files and limits

maxCount caps the list length; one replaces the current file.

```tsx preview
import { Upload, Button, Stack } from '@rockshin/tao-ui';
export default function Demo() {
  return (
    <Stack gap="md">
      <Upload multiple maxCount={3} beforeUpload={() => false}>
        <Button>Select up to three files</Button>
      </Upload>
      <Upload maxCount={1} beforeUpload={() => false}>
        <Button variant="secondary">Replace single file</Button>
      </Upload>
    </Stack>
  );
}
```

### Confirm removal

onRemove can reject removal synchronously or asynchronously. This example protects files with a switch.

```tsx preview
import { Upload, Button, Switch } from '@rockshin/tao-ui';
import { useState } from 'react';
export default function Demo() {
  const [locked, setLocked] = useState(true);
  return (
    <div>
      <label>
        <Switch checked={locked} onChange={setLocked} /> Protect files
      </label>
      <Upload beforeUpload={() => false} onRemove={() => !locked}>
        <Button>Select file</Button>
      </Upload>
    </div>
  );
}
```

</section>

### Extra list information

Render per-file information and choose which list actions appear.

```tsx preview
import { Upload, Button } from '@rockshin/tao-ui';
export default function Demo() {
  return (
    <Upload
      beforeUpload={() => false}
      showUploadList={{
        extra: (file) => (
          <small>{Math.ceil((file.size ?? 0) / 1024)} KB · local file</small>
        ),
        showDownloadIcon: false,
      }}
    >
      <Button>Select document</Button>
    </Upload>
  );
}
```

## Connect an upload service

The live examples keep files locally and send no data. Real uploads need a server endpoint: set action to its URL, or use customRequest for your own request, progress and abort behavior.

```tsx
import { Upload, Button } from '@rockshin/tao-ui';

// The application must implement this endpoint.
export function ServerUpload() {
  return (
    <Upload action="/api/uploads" name="file" data={{ folder: 'documents' }}>
      <Button>Upload to server</Button>
    </Upload>
  );
}
```
