Groups related content, actions and tabbed views in a surface.

This native tao-ui component follows the public API of Ant Design 6.7.0. Appearance, theme tokens and Semantic DOM customization belong to tao-ui; configure themes with `TaoProvider`.

The public Card API follows 6.7.0; styling uses tao-ui tokens and Semantic DOM. Tabs use the low-level rc tabs engine with native tao-ui styles.

## When to use

Use cards for self-contained records. Use explicit links or buttons for actions.

### Title and extra action

```tsx preview
import { useState } from "react";
import { Button, Card } from "@rockshin/tao-ui";

export default function Example() {
  const [saved, setSaved] = useState(false);
  return (
    <Card
      title="Workspace"
      extra={
        <Button size="small" onClick={() => setSaved(!saved)}>
          {saved ? "Saved" : "Save"}
        </Button>
      }
    >
      Keep related project information together.
    </Card>
  );
}
```

### Cover, metadata and actions

```tsx preview
import { useState } from "react";
import { Avatar, Button, Card } from "@rockshin/tao-ui";

export default function Example() {
  const [saved, setSaved] = useState(false);
  const [message, setMessage] = useState("");
  return (
    <Card
      hoverable
      cover={
        <div
          style={{
            height: 110,
            background: "linear-gradient(120deg, #e6ded0, #91b2b1)",
          }}
        />
      }
      actions={[
        <Button key="save" size="small" onClick={() => setSaved(!saved)}>
          {saved ? "Saved" : "Save"}
        </Button>,
        <Button
          key="share"
          size="small"
          onClick={() => setMessage("Read-only access for all team members")}
        >
          Details
        </Button>,
      ]}
    >
      <Card.Meta
        avatar={<Avatar>AL</Avatar>}
        title="Design notes"
        description={message || "Updated today by Ada"}
      />
    </Card>
  );
}
```

### Controlled tabs

```tsx preview
import { useState } from "react";
import { Card } from "@rockshin/tao-ui";

export default function Example() {
  const [tab, setTab] = useState("overview");
  return (
    <Card
      title="Project"
      tabList={[
        { key: "overview", label: "Overview" },
        { key: "activity", label: "Activity" },
      ]}
      activeTabKey={tab}
      onTabChange={setTab}
      tabProps={{ animated: true }}
    >
      <p>
        {tab === "overview"
          ? "Project summary and owners."
          : "The latest project activity."}
      </p>
    </Card>
  );
}
```

</section>
