Displays labelled fields in a structured record view.

This native tao-ui component follows the public API of Ant Design 6.7.0. Appearance, theme tokens and Semantic DOM customization belong to tao-ui; configure themes with `TaoProvider`.

Items, responsive columns and spans follow 6.7.0. The default columns adapt from one on phones to three on desktop, using tao-ui breakpoints.

## When to use

Use for read-only account, order or configuration details.

### Actions and semantic styling

```tsx preview
import { useState } from "react";
import { Button, Descriptions } from "@rockshin/tao-ui";

const items = [
  { key: "name", label: "Name", children: "Ada Lovelace" },
  { key: "plan", label: "Plan", children: "Team" },
  { key: "region", label: "Region", children: "London" },
  { key: "status", label: "Status", children: "Active" },
];

export default function Example() {
  const [editing, setEditing] = useState(false);
  return (
    <Descriptions
      title="Billing details"
      extra={
        <Button size="small" onClick={() => setEditing(!editing)}>
          {editing ? "Show less" : "Show all"}
        </Button>
      }
      items={editing ? items : items.slice(0, 2)}
      styles={{
        label: { color: "var(--tao-color-text-secondary)" },
        content: { fontWeight: 600 },
      }}
    />
  );
}
```
