Indicates indeterminate loading activity.

## When to use

Use Spinner for short indeterminate waits when progress cannot be measured.

**Recommended**

- Prefer inline placement near the content that is loading.
- Use aria labels for standalone spinners.

**Avoid**

- Do not use Spinner for determinate progress.

### Content overlay and delay

```tsx preview
import { Button, Spinner, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

function SpinnerOverlay() {
  const [spinning, setSpinning] = useState(true);

  return (
    <Stack gap="md" style={{ maxWidth: 420 }}>
      <Button
        variant="secondary"
        onClick={() => setSpinning((value) => !value)}
      >
        {spinning ? 'Stop' : 'Start'} loading
      </Button>
      <Spinner spinning={spinning} delay={200} tip="Loading content">
        <div
          style={{
            minHeight: 120,
            padding: 20,
            border: '1px solid var(--tao-color-border)',
          }}
        >
          Content remains mounted below the overlay.
        </div>
      </Spinner>
    </Stack>
  );
}

export default SpinnerOverlay;
```

### Loading over content

spinning controls loading over a content area.

```tsx preview
import { Spinner, Stack } from '@rockshin/tao-ui';

import { useState } from 'react';

export default function SpinnerWrapContent() {
  function Demo() {
    const [spinning, setSpinning] = useState(true);
    return (
      <Stack gap="md" style={{ maxWidth: 360 }}>
        <button type="button" onClick={() => setSpinning((s) => !s)}>
          {spinning ? 'Stop' : 'Start'} loading
        </button>
        <Spinner spinning={spinning} tip="Loading">
          <div
            style={{
              padding: 24,
              border: '1px solid var(--tao-color-border)',
              borderRadius: 8,
              lineHeight: 1.6,
            }}
          >
            <h4 style={{ margin: '0 0 8px' }}>Card title</h4>
            <p style={{ margin: 0 }}>
              Content stays in place and dims while the spinner overlays it.
            </p>
          </div>
        </Spinner>
      </Stack>
    );
  }
  return <Demo />;
}
```

### Delayed loading

A short request can finish before delay to avoid flicker.

```tsx preview
import { Spinner, Stack } from '@rockshin/tao-ui';

import { useState } from 'react';

export default function SpinnerDelay() {
  function Demo() {
    const [spinning, setSpinning] = useState(false);
    return (
      <Stack gap="md" style={{ maxWidth: 360 }}>
        <p style={{ color: 'var(--tao-color-text-secondary)', fontSize: 13 }}>
          500ms delay — quick toggles won&apos;t flash the spinner.
        </p>
        <button type="button" onClick={() => setSpinning((s) => !s)}>
          Toggle spinning ({String(spinning)})
        </button>
        <Spinner spinning={spinning} delay={500}>
          <div
            style={{
              padding: 24,
              border: '1px solid var(--tao-color-border)',
              borderRadius: 8,
            }}
          >
            Toggle quickly to see the delay in action.
          </div>
        </Spinner>
      </Stack>
    );
  }
  return <Demo />;
}
```

### Controlled loading

Control spinning externally while keeping content in place.

```tsx preview
import { useState } from 'react';
import { Spinner, Switch, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [loading, setLoading] = useState(false);
  return (
    <Stack direction="vertical">
      <Switch
        aria-label="Loading"
        checked={loading}
        onChange={setLoading}
        style={{ alignSelf: 'flex-start' }}
      />
      <Spinner spinning={loading} tip="Loading content">
        <div style={{ padding: 24 }}>Your workspace content stays here.</div>
      </Spinner>
    </Stack>
  );
}
```
