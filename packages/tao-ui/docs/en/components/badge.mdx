Shows counts, compact status indicators and ribbons.

This native tao-ui component follows the public API of Ant Design 6.7.0. Appearance, theme tokens and Semantic DOM customization belong to tao-ui; configure themes with `TaoProvider`.

Badge follows the 6.7.0 count/status API; colors and Ribbon surfaces use tao-ui tokens. Count changes update directly.

## When to use

Attach counts to a relevant control; include text when communicating status.

### Change a count

```tsx preview
import { useState } from "react";
import { Badge, Button } from "@rockshin/tao-ui";

export default function Example() {
  const [count, setCount] = useState(5);
  return (
    <div
      style={{
        display: "flex",
        gap: 16,
        alignItems: "center",
        flexWrap: "wrap",
      }}
    >
      <Badge count={count} showZero />
      <Button onClick={() => setCount(Math.max(0, count - 1))}>−</Button>
      <Button onClick={() => setCount(count + 1)}>+</Button>
    </div>
  );
}
```

</section>
