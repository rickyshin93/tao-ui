Switches between peer panels within the same page context.

## When to use

Use Tabs to separate peer views without navigating away from the current task.

**Recommended**

- Use short tab labels.
- Keep tab panels at comparable hierarchy.

**Avoid**

- Do not use Tabs for sequential steps.

### Controlled and disabled tabs

```tsx preview
import { Tabs } from '@rockshin/tao-ui';
import { useState } from 'react';

function ControlledTabs() {
  const [activeKey, setActiveKey] = useState('general');

  return (
    <Tabs
      activeKey={activeKey}
      onChange={setActiveKey}
      items={[
        { key: 'general', label: 'General', children: 'General settings.' },
        { key: 'security', label: 'Security', children: 'Security settings.' },
        {
          key: 'billing',
          label: 'Billing',
          children: 'Unavailable.',
          disabled: true,
        },
      ]}
    />
  );
}

export default ControlledTabs;
```

### Externally controlled tabs

Use `activeKey` and `onChange` to keep tab selection in application state.

```tsx preview
import { Stack, Tabs } from '@rockshin/tao-ui';

import { useState } from 'react';

const basicItems = [
  { key: 'general', label: 'General', children: 'General settings content.' },
  {
    key: 'security',
    label: 'Security',
    children: 'Security settings content.',
  },
  {
    key: 'notifications',
    label: 'Notifications',
    children: 'Notification preferences.',
  },
];

export default function TabsControlled() {
  function Demo() {
    const [key, setKey] = useState('security');
    return (
      <Stack gap="md">
        <Tabs items={basicItems} activeKey={key} onChange={setKey} />
        <p style={{ color: 'var(--tao-color-text-secondary)', fontSize: 13 }}>
          activeKey: {key}
        </p>
      </Stack>
    );
  }
  return <Demo />;
}
```

### Provider size and local overrides

Inherit the provider size and explicitly override an individual tab group when needed.

```tsx preview
import { Tabs, TaoProvider } from '@rockshin/tao-ui';

const basicItems = [
  { key: 'general', label: 'General', children: 'General settings content.' },
  {
    key: 'security',
    label: 'Security',
    children: 'Security settings content.',
  },
  {
    key: 'notifications',
    label: 'Notifications',
    children: 'Notification preferences.',
  },
];

export default function TabsProviderInherit() {
  return (
    <TaoProvider size="large">
      <Tabs items={basicItems} variant="card" />
    </TaoProvider>
  );
}
```
