Choose one or more values, search options, create tags, and customize their presentation. The examples below cover the currently supported capabilities and can each be copied and run independently.

Examples normally adapt to a mobile drawer. Those described as desktop examples explicitly set `mobile={false}` to demonstrate input, menu, or popup-specific behavior.

### Basic usage

Define choices with `options` and an initial selection with `defaultValue`. `FormField` gives the control an accessible label.

```tsx preview
import { FormField, Select } from '@rockshin/tao-ui';

export default function BasicSelect() {
  return (
    <FormField label="Framework">
      <Select
        defaultValue="react"
        placeholder="Choose a framework"
        options={[
          { label: 'React', value: 'react' },
          { label: 'Vue', value: 'vue' },
          { label: 'Svelte', value: 'svelte' },
        ]}
      />
    </FormField>
  );
}
```

</section>

### Three sizes

Use `small`, `medium`, and `large` for compact toolbars, standard forms, and prominent controls. Desktop option text and row height follow the control size; mobile drawers retain touch-friendly list sizing.

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';

const options = [
  { label: 'Design', value: 'design' },
  { label: 'Engineering', value: 'engineering' },
];

export default function SelectSizes() {
  return (
    <Stack>
      {(['small', 'medium', 'large'] as const).map((size) => (
        <FormField key={size} label={size}>
          <Select size={size} defaultValue="design" options={options} />
        </FormField>
      ))}
    </Stack>
  );
}
```

### Controlled selection

Keep external state in sync with `value` and `onChange`. Clearing a single selection emits an empty string; an external action can also update the value.

```tsx preview
import { Button, FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function ControlledSelect() {
  const [value, setValue] = useState('react');
  return (
    <Stack>
      <FormField label="Controlled framework">
        <Select
          value={value}
          onChange={(next) => setValue(next as string)}
          allowClear
          options={[
            { label: 'React', value: 'react' },
            { label: 'Vue', value: 'vue' },
          ]}
          placeholder="Choose a framework"
        />
      </FormField>
      <output aria-live="polite">Value: {value || '(empty)'}</output>
      <Button variant="secondary" onClick={() => setValue('vue')}>
        Select Vue
      </Button>
    </Stack>
  );
}
```

### Multiple selection

`mode="multiple"` uses an array of strings. Remove a tag or select an option again to deselect it; `allowClear` clears the entire selection.

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function MultipleSelect() {
  const [value, setValue] = useState<string[]>(['design', 'engineering']);
  return (
    <Stack>
      <FormField label="Teams">
        <Select
          mode="multiple"
          showSearch
          allowClear
          value={value}
          onChange={(next) => setValue(next as string[])}
          options={[
            { label: 'Design', value: 'design' },
            { label: 'Engineering', value: 'engineering' },
            { label: 'Research', value: 'research' },
            { label: 'Operations', value: 'operations' },
          ]}
          placeholder="Choose teams"
        />
      </FormField>
      <output aria-live="polite">
        Selected: {value.join(', ') || '(none)'}
      </output>
    </Stack>
  );
}
```

### Selection and clear events

`onChange` provides the full value and matching existing options. `onSelect`, `onDeselect`, and `onClear` describe individual actions. Newly created tags have no existing option object.

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function SelectionEvents() {
  const [value, setValue] = useState<string[]>(['design']);
  const [event, setEvent] = useState('No action yet');
  return (
    <Stack>
      <FormField label="Event example">
        <Select
          mobile={false}
          mode="multiple"
          showSearch
          allowClear
          value={value}
          onChange={(next) => setValue(next as string[])}
          onSelect={(_, option) => setEvent(`Selected: ${option.label}`)}
          onDeselect={(_, option) => setEvent(`Removed: ${option.label}`)}
          onClear={() => setEvent('Cleared all selections')}
          options={['Design', 'Engineering', 'Research'].map((label) => ({
            label,
            value: label.toLowerCase(),
          }))}
          placeholder="Choose teams"
        />
      </FormField>
      <output aria-live="polite">{event}</output>
    </Stack>
  );
}
```

### Dependent selections

When the upstream selection changes, update both the dependent options and value. Here the region determines the available cities.

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

const cities: Record<string, string[]> = {
  Asia: ['Tokyo', 'Singapore'],
  Europe: ['London', 'Berlin'],
};

export default function DependentSelects() {
  const [region, setRegion] = useState('Asia');
  const [city, setCity] = useState('Tokyo');
  return (
    <Stack>
      <FormField label="Region">
        <Select
          value={region}
          options={Object.keys(cities).map((value) => ({
            label: value,
            value,
          }))}
          onChange={(next) => {
            const region = next as string;
            setRegion(region);
            setCity(cities[region][0]);
          }}
        />
      </FormField>
      <FormField label="City">
        <Select
          value={city}
          onChange={(next) => setCity(next as string)}
          options={cities[region].map((value) => ({ label: value, value }))}
        />
      </FormField>
      <output aria-live="polite">
        {region} / {city}
      </output>
    </Stack>
  );
}
```

### Async search and loading

This example simulates a search request with local data and a 500ms delay. It cancels stale work and combines loading, controlled search, and an empty state. Replace the local lookup with your API in an application. It uses desktop input.

```tsx preview
import { FormField, Select, type SelectOption } from '@rockshin/tao-ui';
import { useEffect, useState } from 'react';

const people = [
  { label: 'Maya Chen', value: 'maya', description: 'Design' },
  { label: 'Noah Kim', value: 'noah', description: 'Engineering' },
  { label: 'Lin Wang', value: 'lin', description: 'Research' },
];

export default function AsyncSelect() {
  const [search, setSearch] = useState('');
  const [options, setOptions] = useState<SelectOption[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    setLoading(true);
    setOptions([]);
    const timer = window.setTimeout(() => {
      setOptions(
        people.filter((person) =>
          person.label.toLowerCase().includes(search.toLowerCase()),
        ),
      );
      setLoading(false);
    }, 500);
    return () => window.clearTimeout(timer);
  }, [search]);

  return (
    <FormField
      label="Search people"
      description="Local demo with a simulated 500ms request."
    >
      <Select
        mobile={false}
        showSearch
        allowClear
        searchValue={search}
        onSearch={setSearch}
        options={options}
        loading={loading}
        filterOption={() => true}
        notFoundContent={loading ? 'Searching…' : 'No matching people'}
        placeholder="Try Maya or Noah"
      />
    </FormField>
  );
}
```

</section>

### Prefix, suffix, and action icons

Use `prefix`, `suffixIcon`, `allowClear.clearIcon`, `removeIcon`, and `loadingIcon` for the corresponding slots. Custom icons retain the built-in clear and remove behavior.

```tsx preview
import { FormField, Select, Spinner, Stack } from '@rockshin/tao-ui';

const options = [
  { label: 'Design', value: 'design' },
  { label: 'Engineering', value: 'engineering' },
];
function Icon({ close = false }: { close?: boolean }) {
  return (
    <svg
      width="16"
      height="16"
      viewBox="0 0 20 20"
      fill="none"
      stroke="currentColor"
      strokeWidth="1.5"
      aria-hidden="true"
    >
      <path d={close ? 'm5 5 10 10M15 5 5 15' : 'm5 8 5 5 5-5'} />
    </svg>
  );
}

export default function CustomIcons() {
  return (
    <Stack>
      <FormField label="Custom clear icon">
        <Select
          showSearch
          defaultValue="design"
          options={options}
          prefix={<span>Team</span>}
          suffixIcon={<Icon />}
          allowClear={{ clearIcon: <Icon close /> }}
        />
      </FormField>
      <FormField label="Custom remove icon">
        <Select
          mobile={false}
          mode="multiple"
          showSearch
          defaultValue={['engineering']}
          options={options}
          removeIcon={<Icon close />}
        />
      </FormField>
      <FormField label="Custom loading icon">
        <Select
          loading
```

### Extend the popup

Keep the original menu and add actions through `popupRender`. Here a footer creates a project by name; the Add button preserves input focus. This example uses the desktop popup.

```tsx preview
import { Button, FormField, Input, Select } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function ExtendedPopup() {
  const [projects, setProjects] = useState(['Website', 'Mobile app']);
  const [name, setName] = useState('');
  function addProject() {
    const label = name.trim();
    if (!label || projects.includes(label)) return;
    setProjects([...projects, label]);
    setName('');
  }
  return (
    <FormField label="Project">
      <Select
        mobile={false}
        showSearch
        options={projects.map((label) => ({ label, value: label }))}
        placeholder="Choose or add a project"
        popupRender={(menu) => (
          <>
            {menu}
            <div
              style={{
                display: 'flex',
                gap: 8,
                padding: 12,
                borderTop: '1px solid var(--tao-color-border)',
              }}
            >
              <Input
                aria-label="New project name"
                value={name}
                onChange={(event) => setName(event.target.value)}
                placeholder="New project"
              />
              <Button
                disabled={!name.trim() || projects.includes(name.trim())}
                onMouseDown={(event) => event.preventDefault()}
                onClick={addProject}
              >
                Add
              </Button>
            </div>
          </>
        )}
      />
    </FormField>
  );
}
```

### Controlled open and focus

Control popup visibility with `open` and `onOpenChange`. Use the ref methods `focus()` and `blur()` to coordinate external actions.

```tsx preview
import {
  Button,
  FormField,
  Select,
  type SelectRef,
  Stack,
} from '@rockshin/tao-ui';
import { useRef, useState } from 'react';

export default function OpenAndFocus() {
  const ref = useRef<SelectRef>(null);
  const [open, setOpen] = useState(false);
  return (
    <Stack>
      <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
        <Button
          variant="secondary"
          onClick={() => {
            ref.current?.focus();
            setOpen(true);
          }}
        >
          Open choices
        </Button>
        <Button
          variant="secondary"
          onClick={() => {
            setOpen(false);
            ref.current?.blur();
          }}
        >
          Close and blur
        </Button>
      </div>
      <FormField label="Controlled popup">
        <Select
          ref={ref}
          mobile={false}
          showSearch
          open={open}
          onOpenChange={setOpen}
          options={[
            { label: 'Design', value: 'design' },
            { label: 'Engineering', value: 'engineering' },
          ]}
          placeholder="Choose a team"
        />
      </FormField>
      <output aria-live="polite">Popup: {open ? 'open' : 'closed'}</output>
    </Stack>
  );
}
```

### Form submission

Desktop single-select can use `name` with native `FormData`; `id` associates the field label. Serialize controlled values explicitly for multiple selection and mobile drawers. This demo displays the result without sending a request.

```tsx preview
            id={id}
            name="team"
            mobile={false}

            defaultValue="design"
            options={[
              { label: 'Design', value: 'design' },
              { label: 'Engineering', value: 'engineering' },

          />
        </FormField>

  );
}
```

## Usage notes

- For a few mutually exclusive choices that should be compared directly, prefer [Radio](/components/radio).
- Single selection uses a string; multiple selection and tags use arrays. The second `onChange` argument contains matching existing options. A newly created tag may not have a matching option object.
- The tag overflow example uses a numeric `maxTagCount` to demonstrate a fixed number of visible tags.
- Mobile drawers support search, groups, custom options, and single/multiple confirmation. Examples marked as desktop use `mobile={false}` to demonstrate input and popup interactions. Placement, popup width, and portal containers configure desktop popups.
- Desktop single-select supports native form submission through `name`. Serialize controlled values in application submission logic for mobile and multiple selection.

## API

<API moduleName="select" />

### SelectOption

| Property | Type | Description |
| --- | --- | --- |
| `label` | `ReactNode` | Option text; prefer a string for default filtering and trigger display. |
| `value` | `string` | Unique value; groups also need a stable value. |
| `disabled` | `boolean` | Prevent selecting or removing this option. |
| `icon` | `ReactNode` | Option icon. |
| `description` | `ReactNode` | Supporting text. |
| `options` | `SelectOption[]` | Nested options; makes the entry a group. |

### TagRenderProps

`tagRender` receives `{ label, value, closable, disabled, onClose }`. Use `closable` to decide whether to offer removal, and call `onClose` to perform it.

### SelectRef

The ref exposes `focus()`, `blur()`, and `nativeElement`. Avoid depending on private DOM structure.
