Headless numeric input primitives and hook for custom number entry experiences.

## When to use

Use the headless API when tao-ui styling is not appropriate but number formatting behavior should stay consistent.

**Recommended**

- Use useNumberInput for fully custom rendering.
- Reuse the validation helpers for parity with the styled InputNumber.

**Avoid**

- Do not use the component outside its intended interaction model.

### Basic usage

```tsx preview
import { HeadlessInputNumber } from '@rockshin/tao-ui';
import { useState } from 'react';

function HeadlessInputNumberExample() {
  const [value, setValue] = useState('');

  return (
    <HeadlessInputNumber
      value={value}
      onChange={setValue}
      prefix="$"
      decimalPlaces={2}
      thousandsSeparator=","
      placeholder="Enter amount"
    />
  );
}

export default HeadlessInputNumberExample;
```

### Thousands separators

Configure grouping and decimal separators and compare display with the emitted value.

```tsx preview
import { useState } from 'react';

import { HeadlessInputNumber } from '@rockshin/tao-ui';

function ControlledWrapper(
  props: React.ComponentProps<typeof HeadlessInputNumber>,
) {
  const [value, setValue] = useState((props.value as string | undefined) ?? '');
  return (
    <div
      style={{
        display: 'flex',
        flexDirection: 'column',
        gap: 12,
        minWidth: 0,
        width: '100%',
        maxWidth: 320,
      }}
    >
      <HeadlessInputNumber
        {...props}
        value={value}
        onChange={(v) => {
          setValue(v);
          props.onChange?.(v);
        }}
      />
      <code
        style={{
          background: 'var(--tao-color-bg-container)',
          padding: 8,
          borderRadius: 4,
        }}
      >
        actual value: {JSON.stringify(value)}
      </code>
    </div>
  );
}

export default function HeadlessInputNumberWithThousandSeparator() {
  const args: React.ComponentProps<typeof HeadlessInputNumber> = {
    placeholder: 'Try 1234567',
    decimalPlaces: 2,
    thousandsSeparator: ',',
    decimalSeparator: '.',
  };
  return <ControlledWrapper {...args} />;
}
```

## Regional formatting

Regional grouping, decimal symbols and digits inherit `TaoProvider.locale.numberLocale`; set `locale="fr-FR"` on this component to override it. Explicit separators take precedence. Numeric input keeps canonical ASCII strings and precision while displaying localized digits.
