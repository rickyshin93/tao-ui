Associates labels, help text, validation state, and controls.

## When to use

Use FormField to provide accessible labeling and status text around a single control.

**Recommended**

- Connect every input with a visible label.
- Keep validation copy specific and actionable.

**Avoid**

- Do not use the component outside its intended interaction model.

### Complete form composition

Compose layout, fields, and actions with native submission feedback.

```tsx preview
import { useState } from 'react';
import {
  FormLayout,
  FormSection,
  FormField,
  FormActions,
  Input,
  Textarea,
  Button,
} from '@rockshin/tao-ui';
export default function Example() {
  const [saved, setSaved] = useState('');
  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        setSaved(String(new FormData(e.currentTarget).get('name')));
      }}
      onReset={() => setSaved('')}
    >
      <FormLayout>
        <FormSection title="Profile" description="Public workspace information">
          <FormField label="Display name" required>
            <Input name="name" required defaultValue="Alex" />
          </FormField>
          <FormField label="Bio" description="A short introduction">
            <Textarea name="bio" autoSize />
          </FormField>
        </FormSection>
        <FormActions>
          <Button type="reset">Reset</Button>
          <Button type="submit" variant="primary">
            Save
          </Button>
        </FormActions>
        <output aria-live="polite">
          {saved ? `Saved ${saved}` : 'No changes saved'}
        </output>
      </FormLayout>
    </form>
  );
}
```

### Error feedback and recovery

Update errors with input while the field label remains associated with its control.

```tsx preview
import { useState } from 'react';
import { FormField, Input } from '@rockshin/tao-ui';
export default function Example() {
  const [value, setValue] = useState('');
  return (
    <FormField
      label="Project code"
      required
      error={value.length < 3 ? 'Enter at least 3 characters' : undefined}
    >
      <Input value={value} onChange={(e) => setValue(e.target.value)} />
    </FormField>
  );
}
```

</section>

### Explicit association

Use htmlFor and an input id when integrating existing form identifiers; useId avoids duplicates.

```tsx preview
import { useId } from 'react';
import { FormField, Input } from '@rockshin/tao-ui';
export default function Example() {
  const id = useId();
  return (
    <FormField
      label="Account email"
      htmlFor={id}
      description="Used for account notifications"
    >
      <Input id={id} type="email" />
    </FormField>
  );
}
```
