Associates labels, help text, validation state, and controls.

## When to use

Use FormField to provide accessible labeling and status text around a single control.

**Recommended**

- Connect every input with a visible label.
- Keep validation copy specific and actionable.

**Avoid**

- Do not use the component outside its intended interaction model.

## Basic usage

```tsx preview
import { FormField, Input } from '@rockshin/tao-ui';

function FormFieldExample() {
  return (
    <FormField
      label="Email"
      required
      description="Used for account notifications."
    >
      <Input placeholder="you@example.com" />
    </FormField>
  );
}

export default FormFieldExample;
```

## Description and error states

```tsx preview
import { FormField, Input, Stack } from '@rockshin/tao-ui';

function FormFieldStates() {
  return (
    <Stack gap="lg" style={{ maxWidth: 420 }}>
      <FormField label="Workspace name" description="Visible to all members.">
        <Input placeholder="Acme Design" />
      </FormField>
      <FormField label="Slug" required error="Use lowercase letters and hyphens only.">
        <Input value="Acme Team" error readOnly />
      </FormField>
    </Stack>
  );
}

export default FormFieldStates;
```

## Semantic parts

```tsx preview
import { FormField, Input } from '@rockshin/tao-ui';

function CustomizedFormField() {
  return (
    <FormField
      label="API token"
      description="Stored securely."
      styles={{
        label: { fontWeight: 600 },
        description: { maxWidth: 320 },
      }}
    >
      <Input type="password" value="secret-token" readOnly />
    </FormField>
  );
}

export default CustomizedFormField;
```
