Highlights an active surface with a moving border light.

This native tao-ui component follows the public API of Ant Design 6.7.0. Appearance, theme tokens and Semantic DOM customization belong to tao-ui; configure themes with `TaoProvider`.

Props follow the 6.7.0 beam API. The child must expose a native DOM ref or nativeElement handle. Motion uses transform and respects reduced-motion preferences.

## When to use

Use sparingly for a meaningful active or processing state. Keep an explicit text status alongside the effect.

export default function Example() {
  return (

export default function Example() {

### Toggle a meaningful active state

```tsx preview
import { useState } from "react";
import { BorderBeam, Button, Card } from "@rockshin/tao-ui";

export default function Example() {
  const [active, setActive] = useState(true);
  return (
    <div>
      <Button onClick={() => setActive(!active)} style={{ marginBottom: 16 }}>
        {active ? "Pause" : "Resume"}
      </Button>
      <BorderBeam count={2} items={active ? undefined : []}>
        <Card title={active ? "Syncing changes" : "Paused"}>
          The border animation follows the current state.
        </Card>
      </BorderBeam>
    </div>
  );
}
```

</section>
