Orders events and milestones along a vertical or horizontal rail.

This native tao-ui component follows the public API of Ant Design 6.7.0. Appearance, theme tokens and Semantic DOM customization belong to tao-ui; configure themes with `TaoProvider`.

The 6.7.0 title/content/placement API is supported alongside legacy label/children/position aliases. Numeric titleSpan uses a 24-column proportion.

## When to use

Use for activity history or a sequence of events, not for selecting a current step.

### Pending and reverse order

```tsx preview
import { useState } from "react";
import { Button, Timeline } from "@rockshin/tao-ui";

const items = [
  { title: "09:00", content: "Workspace created", color: "green" },
  { title: "09:20", content: "Members invited" },
  { title: "09:45", content: "First task completed" },
];

export default function Example() {
  const [reverse, setReverse] = useState(false);
  return (
    <div>
      <Button onClick={() => setReverse(!reverse)} style={{ marginBottom: 16 }}>
        Reverse order
      </Button>
      <Timeline
        items={items}
        pending="Waiting for confirmation"
        reverse={reverse}
      />
    </div>
  );
}
```

</section>
