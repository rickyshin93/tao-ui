Moves through paged data with current page and page-size controls.

## When to use

Use Pagination when a collection is split into pages rather than infinitely loaded.

**Recommended**

- Keep the current page controlled when data is loaded remotely.
- Show total counts when they help users judge scope.

**Avoid**

- Do not use the component outside its intended interaction model.

### Basic usage

```tsx preview
import { Pagination } from '@rockshin/tao-ui';
import { useState } from 'react';

function PaginationExample() {
  const [page, setPage] = useState(1);

  return (
    <Pagination
      total={95}
      current={page}
      pageSize={10}
      onChange={setPage}
      showTotal={(total, range) => range[0] + '-' + range[1] + ' of ' + total}
    />
  );
}

export default PaginationExample;
```

### Page size and totals

```tsx preview
import { Pagination } from '@rockshin/tao-ui';
import { useState } from 'react';

function PaginationPageSize() {
  const [page, setPage] = useState(1);
  const [pageSize, setPageSize] = useState(10);

  return (
    <Pagination
      total={200}
      current={page}
      pageSize={pageSize}
      showSizeChanger
      showTotal={(total, range) => range[0] + '-' + range[1] + ' of ' + total}
      onChange={(nextPage, nextPageSize) => {
        setPage(nextPage);
        setPageSize(nextPageSize);
      }}
    />
  );
}

export default PaginationPageSize;
```

### Display totals

`showTotal` can describe the current record range and total count.

```tsx preview
import { Pagination } from '@rockshin/tao-ui';

import { useState } from 'react';

export default function PaginationWithTotal() {
  function Demo() {
    const [page, setPage] = useState(1);
    return (
      <Pagination
        total={95}
        current={page}
        pageSize={10}
        onChange={(p) => setPage(p)}
        showTotal={(t, [s, e]) => `${s}-${e} of ${t}`}
      />
    );
  }
  return <Demo />;
}
```

### Change page size

Maintain page and page size together and use both updated values in a data request.

```tsx preview
import { Pagination } from '@rockshin/tao-ui';

import { useState } from 'react';

export default function PaginationSizeChanger() {
  function Demo() {
    const [page, setPage] = useState(1);
    const [ps, setPs] = useState(10);
    return (
      <Pagination
        total={200}
        current={page}
        pageSize={ps}
        onChange={(p, s) => {
          setPage(p);
          setPs(s);
        }}
        showSizeChanger
      />
    );
  }
  return <Demo />;
}
```
