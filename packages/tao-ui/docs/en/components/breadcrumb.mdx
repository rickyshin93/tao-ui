Renders the user location in a hierarchy of pages or views.

## When to use

Use Breadcrumb near the top of a page when users need to understand or move through nested context.

**Recommended**

- Keep labels short and recognizable.
- Use links for ancestors and plain text for the current item.

**Avoid**

- Do not use Breadcrumb as primary navigation.

```tsx preview
function BreadcrumbExample() {
```

### Separators and collapsed paths

```tsx preview
import { Breadcrumb, Stack, TaoProvider } from '@rockshin/tao-ui';

function BreadcrumbSeparators() {
  const items = [
    { title: 'Home', href: '#breadcrumb-example-1' },
    { title: 'Settings', href: '#breadcrumb-example-1' },
    { title: 'Profile' },
  ];

  return (
    <Stack gap="md">
      <Breadcrumb separator="/" items={items} />
      <Breadcrumb separator="›" items={items} />
      <Breadcrumb
        maxItems={3}
        items={[
          { title: 'Home', href: '#breadcrumb-example-1' },
          { title: 'Workspace', href: '#breadcrumb-example-1' },
          { title: 'Projects', href: '#breadcrumb-example-1' },
          { title: 'tao-ui', href: '#breadcrumb-example-1' },
          { title: 'Settings' },
        ]}
      />
    </Stack>
  );
}

export default BreadcrumbSeparators;
```

### Collapsed paths

`maxItems` collapses middle segments; open the overflow menu to reach hidden levels.

```tsx preview
import { Breadcrumb } from '@rockshin/tao-ui';

export default function BreadcrumbCollapsed() {
  return (
    <Breadcrumb
      maxItems={3}

        { title: 'Group', href: '#breadcrumb-example-1' },

        { title: 'Subsection', href: '#breadcrumb-example-1' },
```

### Custom link rendering

Use `itemRender` to integrate an application link component while retaining accessible link behavior.

```tsx preview
import { Breadcrumb } from '@rockshin/tao-ui';

export default function BreadcrumbCustomLink() {
  return (
    <Breadcrumb
      items={[
        { title: 'Home', key: 'home' },
        { title: 'Library', key: 'library' },
        { title: 'Data' },
      ]}
      itemRender={(item, { isLast }) =>
        isLast ? (
          item.title
        ) : (
          // Any custom element works — e.g. a router <Link>. Slot merges the
          // breadcrumb link styles onto it instead of adding another <a>.
          <a href="#breadcrumb-example-1">{item.title}</a>
        )
      }
    />
  );
}
```

### Breadcrumb sizes

Use TaoProvider `size` to match a compact toolbar or a spacious page header.

```tsx preview
import { Breadcrumb, Stack, TaoProvider } from '@rockshin/tao-ui';

export default function BreadcrumbSizes() {
  return (
    <Stack gap="md">
      {(['small', 'medium', 'large'] as const).map((size) => (
        <div key={size}>
          <p
            style={{
              fontSize: 13,
              color: 'var(--tao-color-text-secondary)',
              marginBottom: 4,
            }}
          >
            {size}
          </p>
          <TaoProvider size={size}>
            <Breadcrumb
              items={[
                { title: 'Home', href: '#breadcrumb-example-1' },
                { title: 'List', href: '#breadcrumb-example-1' },
                { title: 'Detail' },
              ]}
            />
          </TaoProvider>
        </div>
      ))}
    </Stack>
  );
}
```
