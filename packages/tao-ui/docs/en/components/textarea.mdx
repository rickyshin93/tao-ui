Multi-line text input with optional auto sizing.

## When to use

Use Textarea for longer freeform content such as descriptions, notes, and comments.

**Recommended**

- Set rows or autoSize based on expected content length.
- Use maxLength when limits are strict.

**Avoid**

- Do not use the component outside its intended interaction model.

### Basic usage

```tsx preview
import { Stack, Textarea } from '@rockshin/tao-ui';

function TextareaExample() {
  return (
    <Stack gap="md" style={{ maxWidth: 420 }}>
      <Textarea placeholder="Write a description" />
      <Textarea
        defaultValue="Autosize grows with its content."
        autoSize={{ minRows: 2, maxRows: 5 }}
      />
      <Textarea value="Invalid content" error readOnly />
    </Stack>
  );
}

export default TextareaExample;
```

### Controlled text and character count

Native maxLength limits input; controlled state displays the character count.

```tsx preview
import { useState } from 'react';
import { Textarea, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [text, setText] = useState('');
  return (
    <Stack direction="vertical">
      <Textarea
        aria-label="Description"
        value={text}
        maxLength={120}
        onChange={(e) => setText(e.target.value)}
      />
      <output>{text.length} / 120</output>
    </Stack>
  );
}
```

```tsx preview
        aria-label="Disabled notes"

      />
```

### Submit and reset

Read content by name and use reset to restore the default value.

```tsx preview
import { useState } from 'react';
import { Textarea, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [saved, setSaved] = useState('');
  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        setSaved(String(new FormData(e.currentTarget).get('notes')));
      }}
      onReset={() => setSaved('')}
    >
      <Stack direction="vertical">
        <Textarea
          name="notes"
          aria-label="Review notes"
          defaultValue="Ready for review"
        />
        <Stack>
          <Button type="submit">Save notes</Button>
          <Button type="reset">Reset</Button>
        </Stack>
        <output aria-live="polite">{saved}</output>
      </Stack>
    </form>
  );
}
```

## Clear and count

`Textarea` and `Input.TextArea` are the same component, supporting `allowClear`, `onClear`, `showCount`, `count`, `onPressEnter`, and `variant="underlined"`. [See the Input family examples and API](./input).
