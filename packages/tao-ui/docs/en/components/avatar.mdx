Identifies people or entities using images, initials or icons.

This native tao-ui component follows the public API of Ant Design 6.7.0. Appearance, theme tokens and Semantic DOM customization belong to tao-ui; configure themes with `TaoProvider`.

Sizes inherit TaoProvider. Square avatars use the native tao-ui radius; group overflow uses the tao-ui Popover.

## When to use

Use short initials and meaningful alternative text. Groups show team membership.

### Automatic text fitting

```tsx preview
import { useState } from "react";
import { Avatar, Button } from "@rockshin/tao-ui";

const labels = ["A", "Ada", "Lovelace"];

export default function Example() {
  const [index, setIndex] = useState(0);
  return (
    <div
      style={{
        display: "flex",
        gap: 16,
        alignItems: "center",
        flexWrap: "wrap",
      }}
    >
      <Avatar size={48} gap={6}>
        {labels[index]}
      </Avatar>
      <Button onClick={() => setIndex((index + 1) % labels.length)}>
        Change name
      </Button>
    </div>
  );
}
```

### Groups and overflow

```tsx preview="iframe-follow"
import { Avatar } from "@rockshin/tao-ui";

export default function Example() {
  return (
    <Avatar.Group
      size="large"
      max={{
        count: 3,
        popover: { trigger: "click" },
        style: { background: "var(--tao-color-fill-secondary)" },
      }}
    >
      {["AL", "BT", "CW", "DX", "EY"].map((name) => (
        <Avatar key={name}>{name}</Avatar>
      ))}
    </Avatar.Group>
  );
}
```
