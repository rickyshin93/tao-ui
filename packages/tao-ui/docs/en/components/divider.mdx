Separates content into readable sections or inline groups.

This native tao-ui component follows the public API of Ant Design 6.7.0. Appearance, theme tokens and Semantic DOM customization belong to tao-ui; configure themes with `TaoProvider`.

Use titlePlacement for the title position and orientation for the axis. TaoProvider controls the default size.

## When to use

Use separators when nearby content has a meaningful boundary.

### Sections and titles

```tsx preview
import { Divider } from "@rockshin/tao-ui";

export default function Example() {
  return (

      <Divider />

}
```
