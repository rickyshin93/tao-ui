Arranges form content with consistent label and control alignment.

## When to use

Use FormLayout to keep dense forms aligned and predictable.

**Recommended**

- Use one layout strategy per form.
- Prefer vertical layout on narrow screens.

**Avoid**

- Do not use the component outside its intended interaction model.

### Basic usage

```tsx preview
import {
  Button,
  FormActions,
  FormField,
  FormLayout,
  FormSection,
  Input,
} from '@rockshin/tao-ui';

function FormLayoutExample() {
  return (
    <FormLayout>
      <FormSection title="Account" description="Your login details.">
        <FormField label="Email" required>
          <Input placeholder="you@example.com" />
        </FormField>
      </FormSection>
      <FormActions>
        <Button variant="ghost">Cancel</Button>
        <Button>Create account</Button>
      </FormActions>
    </FormLayout>
  );
}

export default FormLayoutExample;
```

### Complete form composition

Compose layout, fields, and actions with native submission feedback.

```tsx preview
import { useState } from 'react';
import {
  FormLayout,
  FormSection,
  FormField,
  FormActions,
  Input,
  Textarea,
  Button,
} from '@rockshin/tao-ui';
export default function Example() {
  const [saved, setSaved] = useState('');
  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        setSaved(String(new FormData(e.currentTarget).get('name')));
      }}
      onReset={() => setSaved('')}
    >
      <FormLayout>
        <FormSection title="Profile" description="Public workspace information">
          <FormField label="Display name" required>
            <Input name="name" required defaultValue="Alex" />
          </FormField>
          <FormField label="Bio" description="A short introduction">
            <Textarea name="bio" autoSize />
          </FormField>
        </FormSection>
        <FormActions>
          <Button type="reset">Reset</Button>
          <Button type="submit" variant="primary">
            Save
          </Button>
        </FormActions>
        <output aria-live="polite">
          {saved ? `Saved ${saved}` : 'No changes saved'}
        </output>
      </FormLayout>
    </form>
  );
}
```

</section>

### Responsive form columns

Use CSS Grid on the semantic root to collapse to one column when space is limited.

```tsx preview="iframe-follow"
import { FormLayout, FormField, Input } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <FormLayout
      styles={{
        root: {
          display: 'grid',
          gridTemplateColumns:
            'repeat(auto-fit, minmax(min(100%, 240px), 1fr))',
          gap: 16,
        },
      }}
    >
      <FormField label="First name">
        <Input />
      </FormField>
      <FormField label="Last name">
        <Input />
      </FormField>
      <FormField label="Email">
        <Input type="email" />
      </FormField>
      <FormField label="Organization">
        <Input />
      </FormField>
    </FormLayout>
  );
}
```

### Grouped form sections

Use section titles for hierarchy and the outer layout for spacing.

```tsx preview
import {
  FormLayout,
  FormSection,
  FormField,
  Input,
  Switch,
} from '@rockshin/tao-ui';
export default function Example() {
  return (
    <FormLayout>
      <FormSection title="Account" description="Identity and contact">
        <FormField label="Name">
          <Input />
        </FormField>
      </FormSection>
      <FormSection title="Notifications" description="Delivery preferences">
        <FormField label="Email updates">
          <Switch aria-label="Email updates" defaultChecked />
        </FormField>
      </FormSection>
    </FormLayout>
  );
}
```
