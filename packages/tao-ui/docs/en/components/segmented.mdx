Selects one view or mode from a compact set of choices.

This native tao-ui component follows the public API of Ant Design 6.7.0. Appearance, theme tokens and Semantic DOM customization belong to tao-ui; configure themes with `TaoProvider`.

The 6.7.0 value/options API is rendered with native radios and tao-ui motion. Size inherits TaoProvider; reduced-motion preferences disable the moving highlight.

## When to use

Use for small, closely related choices. Native radio controls support form submission and keyboard selection.

### Controlled selection

```tsx preview
import { useState } from "react";
import { Segmented } from "@rockshin/tao-ui";

export default function Example() {
  const [view, setView] = useState("List");
  return (
    <div>
      <Segmented<string>
        options={["List", "Board", "Calendar"]}
        value={view}
        onChange={setView}
      />
      <p>Current view: {view}</p>
    </div>
  );
}
```

### Submit a native form

```tsx preview
import { useState } from "react";
import { Button, Segmented } from "@rockshin/tao-ui";

export default function Example() {
  const [submitted, setSubmitted] = useState("");
  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        setSubmitted(String(new FormData(event.currentTarget).get("period")));
      }}
    >
      <Segmented
        name="period"
        options={["Day", "Week", "Month"]}
        defaultValue="Week"
      />
      <Button type="submit" style={{ marginLeft: 12 }}>
        Apply
      </Button>
      <p>Submitted: {submitted || "—"}</p>
    </form>
  );
}
```
