输入并格式化货币、百分比及其他数值。

## 何时使用

数值需要范围、小数位、前后缀或本地化分隔符时使用 InputNumber。

**推荐**

- 明确展示单位与格式。
- 范围限制应与错误提示一致。

**避免**

- 普通文本或编号标识不要使用数值输入。

## 基础用法

```tsx preview
import { InputNumber } from '@rockshin/tao-ui';
import { useState } from 'react';

function InputNumberExample() {
  const [value, setValue] = useState('1500');

  return (
    <InputNumber
      value={value}
      onChange={setValue}
      prefix="$"
      suffix="USD"
      decimalPlaces={2}
      thousandsSeparator=","
    />
  );
}

export default InputNumberExample;
```

## 货币与百分比

```tsx preview
import { InputNumber, Stack } from '@rockshin/tao-ui';

function InputNumberFormats() {
  return (
    <Stack gap="md">
      <InputNumber
        defaultValue="150000"
        prefix="€"
        decimalPlaces={2}
        thousandsSeparator=","
      />
      <InputNumber defaultValue="0.42" isPercentage suffix="%" decimalPlaces={1} />
    </Stack>
  );
}

export default InputNumberFormats;
```

## 尺寸、变体与范围
