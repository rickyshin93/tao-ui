输入并格式化货币、百分比及其他数值。

## 何时使用

数值需要范围、小数位、前后缀或本地化分隔符时使用 InputNumber。

**推荐**

- 明确展示单位与格式。
- 范围限制应与错误提示一致。

**避免**

- 普通文本或编号标识不要使用数值输入。

### 基础用法

```tsx preview
import { InputNumber } from '@rockshin/tao-ui';
import { useState } from 'react';

function InputNumberExample() {
  const [value, setValue] = useState('1500');

  return (
    <InputNumber
      value={value}
      onChange={setValue}
      prefix="$"
      suffix="USD"
      decimalPlaces={2}
      thousandsSeparator=","
    />
  );
}

export default InputNumberExample;
```

### 货币格式

千位分隔符、两位小数和前缀只改变展示，输出值便于业务计算。

```tsx preview
import { useState } from 'react';

import { InputNumber } from '@rockshin/tao-ui';

function ControlledWrapper(props: React.ComponentProps<typeof InputNumber>) {
  const [value, setValue] = useState((props.value as string | undefined) ?? '');
  return (
    <div
      style={{
        display: 'flex',
        flexDirection: 'column',
        gap: 12,
        minWidth: 0,
        width: '100%',
        maxWidth: 320,
      }}
    >
      <InputNumber
        {...props}
        value={value}
        onChange={(v) => {
          setValue(v);
          props.onChange?.(v);
        }}
      />
      <code
        style={{
          background: 'var(--tao-color-bg-container)',
          padding: 8,
          borderRadius: 4,
        }}
      >
        actual value: {JSON.stringify(value)}
      </code>
    </div>
  );
}

export default function InputNumberCurrency() {
  const args: React.ComponentProps<typeof InputNumber> = {
    prefix: '€',
    thousandsSeparator: ',',
    decimalSeparator: '.',
    decimalPlaces: 2,
    value: '150000',
    placeholder: 'Amount',
  };
  return <ControlledWrapper {...args} />;
}
```
