展示结构化数据，并支持排序、筛选、选择、分页与响应式列。

## 何时使用

用户需要扫描、比较或操作多行结构化数据时使用 Table。

**推荐**

- 列标题简短且与数据一致。
- 数字列使用一致对齐。
- 为加载和空数据提供明确状态。

**避免**

- 简单键值信息不需要使用 Table。

### 固定表头、展开行与总结栏

`scroll.y` 限制表体高度并让表头吸顶；`expandable` 在行下方展开详情（展开列位于选择列之前）；`summary` 返回 `Table.Summary.Row` / `Table.Summary.Cell` 作为总结栏，`Cell` 的 `index` 从展开列/选择列开始计数，用于同步固定列，`` 在纵向滚动时吸底。

```tsx preview
import { Table } from '@rockshin/tao-ui';

const data = Array.from({ length: 30 }, (_, index) => ({
  id: index + 1,
  name: 'User ' + (index + 1),
  team: ['Design', 'Engineering', 'Sales'][index % 3],
  score: 60 + ((index * 7) % 40),
}));

const columns = [
  {
    key: 'name',
    dataIndex: 'name' as const,
    title: 'Name',
    width: 160,
    fixed: 'left' as const,
  },
  { key: 'team', dataIndex: 'team' as const, title: 'Team', width: 240 },
  {
    key: 'score',
    dataIndex: 'score' as const,
    title: 'Score',
    width: 120,
    align: 'right' as const,
  },
];

function TableAdvanced() {
  return (
    <Table
      columns={columns}
      dataSource={data}
      rowKey="id"
      pagination={false}
      scroll={{ x: 640, y: 280 }}
      expandable={{
        expandedRowRender: (record) =>
          record.name + ' works in ' + record.team + '.',
        rowExpandable: (record) => record.team !== 'Sales',
      }}
      summary={(pageData) => (
        <Table.Summary fixed>
          <Table.Summary.Row>
            <Table.Summary.Cell index={0} colSpan={3}>
              Total
            </Table.Summary.Cell>
            <Table.Summary.Cell index={3} align="right">
              {pageData.reduce((sum, record) => sum + record.score, 0)}
            </Table.Summary.Cell>
          </Table.Summary.Row>
        </Table.Summary>
      )}
    />
  );
}

export default TableAdvanced;
```

### 排序

使用列的排序配置；点击表头在排序方向之间切换。

```tsx preview
import { Table, type TableColumn } from '@rockshin/tao-ui';

interface User {
  id: number;
  name: string;
  age: number;
  email: string;
  role: string;
  department: string;
}

const users: User[] = Array.from({ length: 46 }, (_, i) => ({
  id: i + 1,
  name: ['Alice', 'Bob', 'Charlie', 'Diana', 'Eve', 'Frank', 'Grace', 'Hank'][
    i % 8
  ],
  age: 22 + (i % 20),
  email: `user${i + 1}@example.com`,
  role: i % 3 === 0 ? 'admin' : i % 3 === 1 ? 'editor' : 'viewer',
  department: ['Engineering', 'Design', 'Marketing', 'Sales'][i % 4],
}));

export default function TableSorting() {
  const columns: TableColumn<User>[] = [
    {
      key: 'name',
      dataIndex: 'name',
      title: 'Name',
      sorter: (a, b) => a.name.localeCompare(b.name),
    },
    {
      key: 'age',
      dataIndex: 'age',
      title: 'Age',
      sorter: (a, b) => a.age - b.age,
      defaultSortOrder: 'ascend',
    },
    { key: 'role', dataIndex: 'role', title: 'Role' },
  ];
  return <Table columns={columns} dataSource={users} rowKey="id" />;
}
```

### 受控行选择

用数据库 ID 等稳定标识作为 `rowKey`。将选中的行键存入 `rowSelection.selectedRowKeys`，再通过 `rowSelection.onChange` 更新。

在 `rowSelection.getCheckboxProps(record)` 返回 `{ disabled: true }` 可禁止选择该行。表头复选框只处理当前页可选行，保留其他页的选择。从 [0.0.49](/zh/guide/changelog) 起，组件还会在行状态变化而回调引用保持不变时，按最新的禁用状态全选。

```tsx preview
import { Stack, Table, type TableColumn } from '@rockshin/tao-ui';

import { useState } from 'react';

interface User {
  id: number;
  name: string;
  age: number;
  email: string;
  role: string;
  department: string;
}

const users: User[] = Array.from({ length: 46 }, (_, i) => ({
  id: i + 1,
  name: ['Alice', 'Bob', 'Charlie', 'Diana', 'Eve', 'Frank', 'Grace', 'Hank'][
    i % 8
  ],
  age: 22 + (i % 20),
  email: `user${i + 1}@example.com`,
  role: i % 3 === 0 ? 'admin' : i % 3 === 1 ? 'editor' : 'viewer',
  department: ['Engineering', 'Design', 'Marketing', 'Sales'][i % 4],
}));

const baseColumns: TableColumn<User>[] = [
  { key: 'id', dataIndex: 'id', title: 'ID', width: 60, align: 'center' },
  { key: 'name', dataIndex: 'name', title: 'Name' },
  { key: 'age', dataIndex: 'age', title: 'Age', width: 80 },
  { key: 'email', dataIndex: 'email', title: 'Email' },
  { key: 'role', dataIndex: 'role', title: 'Role' },
];

export default function TableRowSelection() {
  function Demo() {
    const [selectedKeys, setSelectedKeys] = useState<React.Key[]>([]);
    return (
      <Stack gap="sm">
        <p style={{ fontSize: 13, color: 'var(--tao-color-text-secondary)' }}>
          Selected:{' '}
          {selectedKeys.length === 0 ? 'none' : selectedKeys.join(', ')}
        </p>
        <Table
          columns={baseColumns}
          dataSource={users}
          rowKey="id"
          rowSelection={{
            selectedRowKeys: selectedKeys,
            onChange: (keys) => setSelectedKeys(keys),
            getCheckboxProps: (record) => ({
              disabled: record.role === 'viewer',
            }),
          }}
        />
      </Stack>
    );
  }
  return <Demo />;
}
```

</section>
