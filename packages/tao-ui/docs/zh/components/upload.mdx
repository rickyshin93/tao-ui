### 受控文件列表

通过 onChange 接管 fileList；清空按钮同时更新界面。

```tsx preview
import { Upload, Button, Stack, type UploadFile } from '@rockshin/tao-ui';
import { useState } from 'react';
export default function Demo() {
  const [files, setFiles] = useState<UploadFile[]>([]);
  return (
    <Stack gap="md">
      <Upload
        fileList={files}
        beforeUpload={() => false}
        onChange={(info) => setFiles(info.fileList)}
      >
        <Button>Select files</Button>
      </Upload>
      <Button variant="secondary" onClick={() => setFiles([])}>
        Clear list
      </Button>
    </Stack>
  );
}
```

</section>

### 类型校验与忽略

LIST_IGNORE 阻止不符合要求的文件进入列表；浏览器 accept 仅用于选择提示。

```tsx preview
import { Upload, Button } from '@rockshin/tao-ui';
import { useState } from 'react';
export default function Demo() {
  const [error, setError] = useState('');
  return (
    <div>
      <Upload
        accept="image/*"
        beforeUpload={(file) => {
          if (!file.type.startsWith('image/')) {
            setError('Choose an image file.');
            return Upload.LIST_IGNORE;
          }
          setError('');
          return false;
        }}
      >
        <Button>Select image</Button>
      </Upload>
      <p role="status">{error}</p>
    </div>
  );
}
```

</section>

### 确认移除

onRemove 可同步或异步拒绝移除；示例通过开关控制保留文件。

```tsx preview
import { Upload, Button, Switch } from '@rockshin/tao-ui';
import { useState } from 'react';
export default function Demo() {
  const [locked, setLocked] = useState(true);
  return (
    <div>
      <label>
        <Switch checked={locked} onChange={setLocked} /> Protect files
      </label>
      <Upload beforeUpload={() => false} onRemove={() => !locked}>
        <Button>Select file</Button>
      </Upload>
    </div>
  );
}
```

</section>

### 列表补充信息

```tsx preview

export default function Demo() {
  return (
    <Upload
      beforeUpload={() => false}
      showUploadList={{
        extra: (file) => (
          <small>{Math.ceil((file.size ?? 0) / 1024)} KB · local file</small>
        ),
        showDownloadIcon: false,
      }}
    >
      <Button>Select document</Button>
    </Upload>
  );
}
```

## 连接上传服务

官网示例只使用本地文件。接入服务端时，将 `action` 设为上传接口地址，`name` 设为服务端接收文件的 multipart 字段名。

```tsx
import { Upload, Button } from '@rockshin/tao-ui';

// The application must implement this endpoint.
export function ServerUpload() {
  return (
    <Upload action="/api/uploads" name="file" data={{ folder: 'documents' }}>
      <Button>Upload to server</Button>
    </Upload>
  );
}
```

使用 `customRequest` 时，通过 `onProgress` 报告进度，每次请求结束时调用一次 `onSuccess` 或 `onError`。如果请求支持取消，返回带有 `abort()` 方法的对象。使用受控 `fileList` 时，把 `onChange` 传回的文件列表保存到状态，以显示每个文件的最新状态。

从 [0.0.49](/zh/guide/changelog) 起，组件还会处理解析 `action` 或 `data` 时的失败，以及 `customRequest` 同步抛出的异常。出错文件显示失败状态，同批其他文件继续上传。
