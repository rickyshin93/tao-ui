从候选列表中选择一个或多个值，也可以搜索、创建标签和定制选项内容。下面按使用场景展示当前支持的能力，每个示例都可以独立复制运行。

示例通常随视口切换到手机抽屉；标注“桌面”的示例显式使用 `mobile={false}`，用于展示输入、菜单或弹层专属能力。

### 基础用法

用 `options` 定义选项，`defaultValue` 设置初始选择。`FormField` 为控件提供可访问的标签。

```tsx preview
import { FormField, Select } from '@rockshin/tao-ui';

export default function BasicSelect() {
  return (
    <FormField label="Framework">
      <Select
        defaultValue="react"
        placeholder="Choose a framework"
        options={[
          { label: 'React', value: 'react' },
          { label: 'Vue', value: 'vue' },
          { label: 'Svelte', value: 'svelte' },
        ]}
      />
    </FormField>
  );
}
```

### 三种尺寸

`small`、`medium`、`large` 分别适用于紧凑工具栏、常规表单和重点操作。桌面下拉选项的字号与行高同步变化；手机抽屉保留便于触摸的列表尺寸。

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';

const options = [
  { label: 'Design', value: 'design' },
  { label: 'Engineering', value: 'engineering' },
];

export default function SelectSizes() {
  return (
    <Stack>
      {(['small', 'medium', 'large'] as const).map((size) => (
        <FormField key={size} label={size}>
          <Select size={size} defaultValue="design" options={options} />
        </FormField>
      ))}
    </Stack>
  );
}
```

</section>

### 受控选择

使用 `value` 和 `onChange` 同步外部状态。单选清除时回调值为空字符串；下方按钮也可以修改选择。

```tsx preview
import { Button, FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function ControlledSelect() {
  const [value, setValue] = useState('react');
  return (
    <Stack>
      <FormField label="Controlled framework">
        <Select
          value={value}
          onChange={(next) => setValue(next as string)}
          allowClear
          options={[
            { label: 'React', value: 'react' },
            { label: 'Vue', value: 'vue' },
          ]}
          placeholder="Choose a framework"
        />
      </FormField>
      <output aria-live="polite">Value: {value || '(empty)'}</output>
      <Button variant="secondary" onClick={() => setValue('vue')}>
        Select Vue
      </Button>
    </Stack>
  );
}
```

### 多选

`mode="multiple"` 使用字符串数组表示选中项。移除标签或再次点击选项取消选择，`allowClear` 一次清空全部。

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function MultipleSelect() {
  const [value, setValue] = useState<string[]>(['design', 'engineering']);
  return (
    <Stack>
      <FormField label="Teams">
        <Select
          mode="multiple"
          showSearch
          allowClear
          value={value}
          onChange={(next) => setValue(next as string[])}
          options={[
            { label: 'Design', value: 'design' },
            { label: 'Engineering', value: 'engineering' },
            { label: 'Research', value: 'research' },
            { label: 'Operations', value: 'operations' },
          ]}
          placeholder="Choose teams"
        />
      </FormField>
      <output aria-live="polite">
        Selected: {value.join(', ') || '(none)'}
      </output>
    </Stack>
  );
}
```

### 最大选择数量

`maxCount` 限制可选数量；达到上限后，未选中的选项不可选。移除一项后恢复。本例固定桌面弹层。

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function MaximumSelection() {
  const [value, setValue] = useState<string[]>(['design']);
  return (
    <Stack>
      <FormField label="Choose up to two teams">
        <Select
          mobile={false}
          mode="multiple"
          showSearch
          maxCount={2}
          value={value}
          onChange={(next) => setValue(next as string[])}
          options={['Design', 'Engineering', 'Research', 'Operations'].map(
            (label) => ({ label, value: label.toLowerCase() }),
          )}
          placeholder="Choose teams"
        />
      </FormField>
      <output aria-live="polite">{value.length} / 2 selected</output>
    </Stack>
  );
}
```

### 自动分词

粘贴 `design,frontend;docs` 后按 Enter，使用 `tokenSeparators` 批量创建标签并去重。`multiple` 模式只接受已有选项的值或文本，`tags` 还能创建新值。

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function TokenizedTags() {
  const [value, setValue] = useState<string[]>([]);
  return (
    <Stack>
      <FormField
        label="Batch labels"
        description="Paste design,frontend;docs, then press Enter."
      >
        <Select
          mobile={false}
          mode="tags"
          showSearch
          tokenSeparators={[',', ';']}
          options={[]}
          notFoundContent={null}
          value={value}
          onChange={(next) => setValue(next as string[])}
          placeholder="Separate labels with , or ;"
        />
      </FormField>
      <output aria-live="polite">Labels: {value.join(', ') || '(none)'}</output>
    </Stack>
  );
}
```

</section>

### 选择与清除事件

`onChange` 提供完整值与已有选项对象；`onSelect`、`onDeselect`、`onClear` 描述具体操作。新创建标签没有对应的已有选项对象。

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function SelectionEvents() {
  const [value, setValue] = useState<string[]>(['design']);
  const [event, setEvent] = useState('No action yet');
  return (
    <Stack>
      <FormField label="Event example">
        <Select
          mobile={false}
          mode="multiple"
          showSearch
          allowClear
          value={value}
          onChange={(next) => setValue(next as string[])}
          onSelect={(_, option) => setEvent(`Selected: ${option.label}`)}
          onDeselect={(_, option) => setEvent(`Removed: ${option.label}`)}
          onClear={() => setEvent('Cleared all selections')}
          options={['Design', 'Engineering', 'Research'].map((label) => ({
            label,
            value: label.toLowerCase(),
          }))}
          placeholder="Choose teams"
        />
      </FormField>
      <output aria-live="polite">{event}</output>
    </Stack>
  );
}
```

</section>

### 联动选择

上游选择变化时同步更新下游选项和当前值，避免残留不属于新列表的值。这里由区域决定可选城市。

```tsx preview
import { FormField, Select, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

const cities: Record<string, string[]> = {
  Asia: ['Tokyo', 'Singapore'],
  Europe: ['London', 'Berlin'],
};

export default function DependentSelects() {
  const [region, setRegion] = useState('Asia');
  const [city, setCity] = useState('Tokyo');
  return (
    <Stack>
      <FormField label="Region">
        <Select
          value={region}
          options={Object.keys(cities).map((value) => ({
            label: value,
            value,
          }))}
          onChange={(next) => {
            const region = next as string;
            setRegion(region);
            setCity(cities[region][0]);
          }}
        />
      </FormField>
      <FormField label="City">
        <Select
          value={city}
          onChange={(next) => setCity(next as string)}
          options={cities[region].map((value) => ({ label: value, value }))}
        />
      </FormField>
      <output aria-live="polite">
        {region} / {city}
      </output>
    </Stack>
  );
}
```

### 异步搜索与加载

用本地数据和 500ms 延迟模拟搜索请求。输入变化时取消旧任务，配合 `loading`、受控搜索和空状态展示完整过程；真实项目可替换为接口请求。本例固定桌面输入模式。

```tsx preview
import { FormField, Select, type SelectOption } from '@rockshin/tao-ui';
import { useEffect, useState } from 'react';

const people = [
  { label: 'Maya Chen', value: 'maya', description: 'Design' },
  { label: 'Noah Kim', value: 'noah', description: 'Engineering' },
  { label: 'Lin Wang', value: 'lin', description: 'Research' },
];

export default function AsyncSelect() {
  const [search, setSearch] = useState('');
  const [options, setOptions] = useState<SelectOption[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    setLoading(true);
    setOptions([]);
    const timer = window.setTimeout(() => {
      setOptions(
        people.filter((person) =>
          person.label.toLowerCase().includes(search.toLowerCase()),
        ),
      );
      setLoading(false);
    }, 500);
    return () => window.clearTimeout(timer);
  }, [search]);

  return (
    <FormField
      label="Search people"
      description="Local demo with a simulated 500ms request."
    >
      <Select
        mobile={false}
        showSearch
        allowClear
        searchValue={search}
        onSearch={setSearch}
        options={options}
        loading={loading}
        filterOption={() => true}
        notFoundContent={loading ? 'Searching…' : 'No matching people'}
        placeholder="Try Maya or Noah"
      />
    </FormField>
  );
}
```

</section>

`labelRender` 控制单选后的展示内容，可以与下拉列表中的文本不同。这里在城市名旁展示机场代码。

```tsx preview
import { FormField, Select } from '@rockshin/tao-ui';
```

### 扩展下拉菜单

`popupRender` 保留原菜单并添加操作区。这里可以输入名称并创建新项目；新增按钮保留输入焦点。本例固定桌面弹层。

```tsx preview
import { Button, FormField, Input, Select } from '@rockshin/tao-ui';
import { useState } from 'react';

export default function ExtendedPopup() {
  const [projects, setProjects] = useState(['Website', 'Mobile app']);
  const [name, setName] = useState('');
  function addProject() {
    const label = name.trim();
    if (!label || projects.includes(label)) return;
    setProjects([...projects, label]);
    setName('');
  }
  return (
    <FormField label="Project">
      <Select
        mobile={false}
        showSearch
        options={projects.map((label) => ({ label, value: label }))}
        placeholder="Choose or add a project"
        popupRender={(menu) => (
          <>
            {menu}
            <div
              style={{
                display: 'flex',
                gap: 8,
                padding: 12,
                borderTop: '1px solid var(--tao-color-border)',
              }}
            >
              <Input
                aria-label="New project name"
                value={name}
                onChange={(event) => setName(event.target.value)}
                placeholder="New project"
              />
              <Button
                disabled={!name.trim() || projects.includes(name.trim())}
                onMouseDown={(event) => event.preventDefault()}
                onClick={addProject}
              >
                Add
              </Button>
            </div>
          </>
        )}
      />
    </FormField>
  );
}
```

### 受控展开与焦点

`open`、`onOpenChange` 控制弹层。通过 `ref` 调用 `focus()` 和 `blur()`，并在外部操作后保持明确的焦点去向。

```tsx preview
import {
  Button,
  FormField,
  Select,
  type SelectRef,
  Stack,
} from '@rockshin/tao-ui';
import { useRef, useState } from 'react';

export default function OpenAndFocus() {
  const ref = useRef<SelectRef>(null);
  const [open, setOpen] = useState(false);
  return (
    <Stack>
      <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
        <Button
          variant="secondary"
          onClick={() => {
            ref.current?.focus();
            setOpen(true);
          }}
        >
          Open choices
        </Button>
        <Button
          variant="secondary"
          onClick={() => {
            setOpen(false);
            ref.current?.blur();
          }}
        >
          Close and blur
        </Button>
      </div>
      <FormField label="Controlled popup">
        <Select
          ref={ref}
          mobile={false}
          showSearch
          open={open}
          onOpenChange={setOpen}
          options={[
            { label: 'Design', value: 'design' },
            { label: 'Engineering', value: 'engineering' },
          ]}
          placeholder="Choose a team"
        />
      </FormField>
      <output aria-live="polite">Popup: {open ? 'open' : 'closed'}</output>
    </Stack>
  );
}
```

### 表单提交

桌面单选可用 `name` 将值交给原生 `FormData`，字段标签使用 `id` 关联。多选和手机抽屉应通过受控值自行序列化。本例提交只显示结果，不发送请求。

```tsx preview
import { Button, FormField, Select, Stack } from '@rockshin/tao-ui';
import { useId, useState } from 'react';

export default function SelectForm() {
  const id = useId();
  const [result, setResult] = useState('Not submitted');
  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        const data = new FormData(event.currentTarget);
        setResult(`Submitted team: ${data.get('team')}`);
      }}
    >
      <Stack>
        <FormField label="Team to submit" htmlFor={id}>
          <Select
            id={id}
            name="team"
            mobile={false}
            showSearch
            defaultValue="design"
            options={[
              { label: 'Design', value: 'design' },
              { label: 'Engineering', value: 'engineering' },
            ]}
          />
        </FormField>
        <Button type="submit">Submit example</Button>
        <output aria-live="polite">{result}</output>
      </Stack>
    </form>
  );
}
```

## 使用说明

- 少量需要直接比较的互斥选项，优先使用 [Radio](/zh/components/radio)。
- 单选使用字符串，多选和标签使用字符串数组；`onChange` 的第二个参数提供匹配到的已有选项。自由输入的新标签不保证有对应选项对象。
- 标签数量示例使用数字 `maxTagCount`，便于观察固定数量的折叠效果。
- 手机抽屉支持搜索、分组、自定义选项和单选/多选确认。标为桌面模式的示例使用 `mobile={false}`，便于演示输入与弹层操作；弹出位置、弹层宽度与挂载容器属于桌面弹层配置。
- 桌面单选的 `name` 可用于原生表单提交。手机和多选使用受控值，在应用的提交逻辑中序列化。

## API

<API moduleName="select" />

### SelectOption

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `label` | `ReactNode` | 选项文本；建议使用字符串，以便默认搜索和触发器展示。 |
| `value` | `string` | 唯一值；分组也需要稳定的值。 |
| `disabled` | `boolean` | 禁止选择或移除该项。 |
| `icon` | `ReactNode` | 选项图标。 |
| `description` | `ReactNode` | 选项辅助说明。 |
| `options` | `SelectOption[]` | 子选项；存在时该项作为分组。 |

### TagRenderProps

`tagRender` 接收 `{ label, value, closable, disabled, onClose }`。用 `closable` 决定是否提供删除操作，并把删除动作交给 `onClose`。

### SelectRef

通过 `ref` 使用 `focus()`、`blur()` 与 `nativeElement`。避免依赖内部 DOM 层级。
