输入多行文本，并支持状态、尺寸、变体与自动高度。

## 何时使用

用户需要输入说明、备注或其他多行内容时使用 Textarea。

**推荐**

- 通过 FormField 提供标签与错误信息。
- 合理限制自动高度范围。

**避免**

- 短单行内容应使用 Input。

### 受控输入与字数

原生 maxLength 限制输入，受控值用于显示剩余字数。

```tsx preview
import { useState } from 'react';
import { Textarea, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [text, setText] = useState('');
  return (
    <Stack direction="vertical">
      <Textarea
        aria-label="Description"
        value={text}
        maxLength={120}
        onChange={(e) => setText(e.target.value)}
      />
      <output>{text.length} / 120</output>
    </Stack>
  );
}
```

### 表单提交与重置

通过 name 读取文本域内容，reset 恢复默认值。

```tsx preview
import { useState } from 'react';
import { Textarea, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [saved, setSaved] = useState('');
  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        setSaved(String(new FormData(e.currentTarget).get('notes')));
      }}
      onReset={() => setSaved('')}
    >
      <Stack direction="vertical">
        <Textarea
          name="notes"
          aria-label="Review notes"
          defaultValue="Ready for review"
        />
        <Stack>
          <Button type="submit">Save notes</Button>
          <Button type="reset">Reset</Button>
        </Stack>
        <output aria-live="polite">{saved}</output>
      </Stack>
    </form>
  );
}
```

</section>

### 定制输入外观

通过语义部件设置文本域样式，保留组件状态与焦点行为。

```tsx preview
import { Textarea } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Textarea
      aria-label="Code notes"
      autoSize
      styles={{ textarea: { fontFamily: 'monospace', lineHeight: 1.8 } }}
      defaultValue="const ready = true;"
    />
  );
}
```
