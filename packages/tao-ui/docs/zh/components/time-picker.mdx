选择时间或时间范围，支持步长、不可选时段、格式和确认流程。

新增 API 对齐 Ant Design 6.7.0，外观、主题与 Semantic DOM 使用 tao-ui。既有组件 API 保持原样。

### 受控时间与清除

值使用 Dayjs，清除时返回 null。

```tsx preview
import { TimePicker } from '@rockshin/tao-ui';
import dayjs, { type Dayjs } from 'dayjs';
import { useState } from 'react';
export default function Demo() {
  const [value, setValue] = useState<Dayjs | null>(
    dayjs('2026-11-04T09:30:00'),
  );
  return (
    <div>
      <TimePicker value={value} onChange={setValue} />
      <p>{value?.format('HH:mm:ss') ?? 'No time selected'}</p>
    </div>
  );
}
```

</section>

### 时分与 12 小时制

format 决定显示的时间列；use12Hours 显示上午和下午。

```tsx preview
import { TimePicker, Stack } from '@rockshin/tao-ui';
import dayjs from 'dayjs';
export default function Demo() {
  return (
    <Stack gap="md">
      <TimePicker format="HH:mm" defaultValue={dayjs('2026-11-04T09:30:00')} />
      <TimePicker
        use12Hours
        format="h:mm a"
        defaultValue={dayjs('2026-11-04T15:00:00')}
      />
    </Stack>
  );
}
```

</section>

### 工作时间限制

限制上午 9 点至下午 6 点，并隐藏禁用的选项。

```tsx preview
import { TimePicker } from '@rockshin/tao-ui';
export default function Demo() {
  return (
    <TimePicker
      format="HH:mm"
      hideDisabledOptions
      disabledTime={() => ({
        disabledHours: () =>
          Array.from({ length: 24 }, (_, i) => i).filter(
            (i) => i < 9 || i > 18,
          ),
        disabledMinutes: (hour) =>
          hour === 18 ? Array.from({ length: 59 }, (_, i) => i + 1) : [],
      })}
    />
  );
}
```

</section>

### 三种尺寸

新增兼容组件的尺寸为 small、middle、large；省略时继承 TaoProvider。

```tsx preview
import { TimePicker, Stack } from '@rockshin/tao-ui';
export default function Demo() {
  return (
    <Stack gap="md">
      {(['small', 'middle', 'large'] as const).map((size) => (
        <TimePicker key={size} size={size} format="HH:mm" placeholder={size} />
      ))}
    </Stack>
  );
}
```

</section>

### 时间范围

RangePicker 同时提交开始与结束时间。

```tsx preview
import { TimePicker } from '@rockshin/tao-ui';
import { useState } from 'react';
export default function Demo() {
  const [label, setLabel] = useState('Choose a range');
  return (
    <div>
      <TimePicker.RangePicker
        format="HH:mm"
        minuteStep={15}
        onChange={(_, strings) =>
          setLabel(strings ? strings.join(' → ') : 'Cleared')
        }
      />
      <p>{label}</p>
    </div>
  );
}
```

</section>

### 确认与立即选择

needConfirm 控制是否先选择再确认。

```tsx preview
import { TimePicker, Stack } from '@rockshin/tao-ui';
export default function Demo() {
  return (
    <Stack gap="md">
      <TimePicker needConfirm format="HH:mm" placeholder="Confirm a time" />
      <TimePicker
        needConfirm={false}
        format="HH:mm"
        placeholder="Select immediately"
      />
    </Stack>
  );
}
```

</section>

### 面板说明

使用 renderExtraFooter 提供与选择有关的说明。

```tsx preview
import { TimePicker } from '@rockshin/tao-ui';
export default function Demo() {
  return (
    <TimePicker
      format="HH:mm"
      renderExtraFooter={() => (
        <span>All appointments use your local time.</span>
      )}
      styles={{ popup: { root: { maxWidth: 320 } } }}
    />
  );
}
```
