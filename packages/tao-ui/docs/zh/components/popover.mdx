在触发器附近展示补充信息或轻量交互内容。

## 何时使用

内容比 Tooltip 更丰富，但不需要完整 Modal 时使用 Popover。

**推荐**

- 选择与触发方式匹配的交互。
- 内容保持紧凑并靠近触发器。

**避免**

- 不要在 Popover 中承载长流程。

### 受控弹层与内部关闭

内容中的按钮可以更新 open，完成后明确关闭弹层。

```tsx preview
import { useState } from 'react';
import { Popover, Button } from '@rockshin/tao-ui';
export default function Example() {
  const [open, setOpen] = useState(false);
  return (
    <Popover
      trigger="click"
      title="Quick action"
      open={open}
      onOpenChange={setOpen}
      content={<Button onClick={() => setOpen(false)}>Done</Button>}
    >
      <Button>Open actions</Button>
    </Popover>
  );
}
```

### 键盘焦点触发

trigger=focus 可用于键盘聚焦时展示辅助内容，关键说明也应在页面可见。

```tsx preview
import { Popover, Input } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Popover
      trigger="focus"
      title="Project code"
      content="Use a short, recognizable identifier."
    >
      <Input aria-label="Project code" placeholder="Focus this input" />
    </Popover>
  );
}
```

### 箭头与延迟

### 弹层中的表单

弹层可以容纳输入和操作；提交后反馈结果并关闭。

```tsx preview
import { useState } from 'react';
import { Popover, Input, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [open, setOpen] = useState(false);
  const [name, setName] = useState('Workspace');
  return (
    <Stack direction="vertical">
      <Popover
        trigger="click"
        open={open}
        onOpenChange={setOpen}
        title="Rename"
        content={
          <form
            onSubmit={(e) => {
              e.preventDefault();
              setName(String(new FormData(e.currentTarget).get('name')));
              setOpen(false);
            }}
          >
            <Stack direction="vertical">
              <Input
                name="name"
                aria-label="New name"
                defaultValue={name}
                required
              />
              <Button type="submit">Save name</Button>
            </Stack>
          </form>
        }
      >
        <Button>Rename project</Button>
      </Popover>
      <output>{name}</output>
    </Stack>
  );
}
```

</section>
