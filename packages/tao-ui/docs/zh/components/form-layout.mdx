为产品级表单提供一致的宽度、区段与操作布局。

## 何时使用

页面需要由多个字段区段与操作区组成完整表单时使用 FormLayout。

**推荐**

- 使用 FormSection 分组相关字段。
- 使用 FormActions 保持操作位置一致。

**避免**

- 不要用 FormLayout 包裹与表单无关的页面内容。

### 基础用法

```tsx preview
import {
  Button,
  FormActions,
  FormField,
  FormLayout,
  FormSection,
  Input,
} from '@rockshin/tao-ui';

function FormLayoutExample() {
  return (
    <FormLayout>
      <FormSection title="Account" description="Your login details.">
        <FormField label="Email" required>
          <Input placeholder="you@example.com" />
        </FormField>
      </FormSection>
      <FormActions>
        <Button variant="ghost">Cancel</Button>
        <Button>Create account</Button>
      </FormActions>
    </FormLayout>
  );
}

export default FormLayoutExample;
```

### 完整表单组合

组合布局、字段与操作区，用原生提交展示保存结果。

```tsx preview
import { useState } from 'react';
import {
  FormLayout,
  FormSection,
  FormField,
  FormActions,
  Input,
  Textarea,
  Button,
} from '@rockshin/tao-ui';
export default function Example() {
  const [saved, setSaved] = useState('');
  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        setSaved(String(new FormData(e.currentTarget).get('name')));
      }}
      onReset={() => setSaved('')}
    >
      <FormLayout>
        <FormSection title="Profile" description="Public workspace information">
          <FormField label="Display name" required>
            <Input name="name" required defaultValue="Alex" />
          </FormField>
          <FormField label="Bio" description="A short introduction">
            <Textarea name="bio" autoSize />
          </FormField>
        </FormSection>
        <FormActions>
          <Button type="reset">Reset</Button>
          <Button type="submit" variant="primary">
            Save
          </Button>
        </FormActions>
        <output aria-live="polite">
          {saved ? `Saved ${saved}` : 'No changes saved'}
        </output>
      </FormLayout>
    </form>
  );
}
```

</section>

### 响应式多列表单

通过语义 root 使用 CSS Grid，空间不足时自动变为单列。

```tsx preview="iframe-follow"
import { FormLayout, FormField, Input } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <FormLayout
      styles={{
        root: {
          display: 'grid',
          gridTemplateColumns:
            'repeat(auto-fit, minmax(min(100%, 240px), 1fr))',
          gap: 16,
        },
      }}
    >
      <FormField label="First name">
        <Input />
      </FormField>
      <FormField label="Last name">
        <Input />
      </FormField>
      <FormField label="Email">
        <Input type="email" />
      </FormField>
      <FormField label="Organization">
        <Input />
      </FormField>
    </FormLayout>
  );
}
```

### 分组表单

用 section 标题表达信息层级，外层布局统一间距。

```tsx preview
import {
  FormLayout,
  FormSection,
  FormField,
  Input,
  Switch,
} from '@rockshin/tao-ui';
export default function Example() {
  return (
    <FormLayout>
      <FormSection title="Account" description="Identity and contact">
        <FormField label="Name">
          <Input />
        </FormField>
      </FormSection>
      <FormSection title="Notifications" description="Delivery preferences">
        <FormField label="Email updates">
          <Switch aria-label="Email updates" defaultChecked />
        </FormField>
      </FormSection>
    </FormLayout>
  );
}
```
