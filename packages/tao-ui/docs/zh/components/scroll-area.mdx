为受限区域提供跨浏览器一致的滚动条与阴影提示。

## 何时使用

局部内容必须限制尺寸并独立滚动时使用 ScrollArea。

**推荐**

- 明确滚动方向和尺寸上限。
- 触摸与键盘用户都应能访问内容。

**避免**

- 不要制造不必要的嵌套滚动区域。

### 基础用法

```tsx preview
import { ScrollArea } from '@rockshin/tao-ui';

function ScrollAreaExample() {
  return (
    <ScrollArea
      maxHeight={180}
      style={{
        border: '1px solid var(--tao-color-border-secondary)',
        borderRadius: 8,
      }}
    >
      <div style={{ padding: 16 }}>
        {Array.from({ length: 12 }, (_, index) => (
          <p key={index}>Activity item {index + 1}</p>
        ))}
      </div>
    </ScrollArea>
  );
}

export default ScrollAreaExample;
```

### 常驻滚动条与自定义尺寸

```tsx preview
import { ScrollArea, Stack } from '@rockshin/tao-ui';

function ScrollbarStyles() {
  const content = Array.from({ length: 10 }, (_, index) => (
    <p key={index}>Scrollable row {index + 1}</p>
  ));

  return (
    <Stack direction="horizontal" gap="lg">
      <ScrollArea type="always" scrollbarSize={4} maxHeight={160}>
        <div style={{ padding: 12 }}>{content}</div>
      </ScrollArea>
      <ScrollArea type="always" scrollbarSize={10} maxHeight={160}>
        <div style={{ padding: 12 }}>{content}</div>
      </ScrollArea>
    </Stack>
  );
}

export default ScrollbarStyles;
```

### 横向滚动

为横向内容设置有限宽度，并用 `orientation` 显示对应滚动条。

```tsx preview
import { ScrollArea, Tag } from '@rockshin/tao-ui';

const items = Array.from({ length: 50 }, (_, i) => `Item ${i + 1}`);

export default function ScrollAreaHorizontal() {
  return (
    <ScrollArea
      direction="horizontal"
      maxWidth={400}
      style={{
        border: '1px solid var(--tao-color-border-secondary)',
        borderRadius: 6,
      }}
    >
      <div
        style={{ display: 'flex', gap: 8, padding: 16, width: 'max-content' }}
      >
        {items.slice(0, 20).map((item) => (
          <Tag key={item} color="primary">
            {item}
          </Tag>
        ))}
      </div>
    </ScrollArea>
  );
}
```

### 双向滚动

内容同时超出宽高时分别滚动，外层页面不承担内容的横向溢出。

```tsx preview
import { ScrollArea } from '@rockshin/tao-ui';

const items = Array.from({ length: 50 }, (_, i) => `Item ${i + 1}`);

export default function ScrollAreaBoth() {
  return (
    <ScrollArea
      direction="both"
      maxHeight={200}
      maxWidth={300}
      style={{
        border: '1px solid var(--tao-color-border-secondary)',
        borderRadius: 6,
      }}
    >
      <div style={{ width: 600, padding: 16 }}>
        {items.map((item) => (
          <p
            key={item}
            style={{
              margin: '0 0 8px',
              color: 'var(--tao-color-text-secondary)',
              whiteSpace: 'nowrap',
            }}
          >
            {item} — This is a long line that overflows the container
            horizontally to demonstrate both scrollbars.
          </p>
        ))}
      </div>
    </ScrollArea>
  );
}
```

### 始终显示滚动条

`type="always"` 保留滚动条轨道，适用于滚动能力需要更明显的区域。

```tsx preview
import { ScrollArea } from '@rockshin/tao-ui';

const items = Array.from({ length: 50 }, (_, i) => `Item ${i + 1}`);

export default function ScrollAreaAlwaysVisible() {
  return (
    <ScrollArea
      type="always"
      maxHeight={200}
      style={{
        border: '1px solid var(--tao-color-border-secondary)',
        borderRadius: 6,
      }}
    >
      <div style={{ padding: 16 }}>
        {items.map((item) => (
          <p
            key={item}
            style={{
              margin: '0 0 8px',
              color: 'var(--tao-color-text-secondary)',
            }}
          >
            {item}
          </p>
        ))}
      </div>
    </ScrollArea>
  );
}
```

### 滚动条尺寸

调整滚动条尺寸，示例保留有界内容区域。

```tsx preview
import { ScrollArea, Stack } from '@rockshin/tao-ui';

const items = Array.from({ length: 50 }, (_, i) => `Item ${i + 1}`);

export default function ScrollAreaCustomSize() {
  return (
    <Stack gap="lg">
      <div>
        <p
          style={{
            fontSize: 13,
            color: 'var(--tao-color-text-secondary)',
            marginBottom: 8,
          }}
        >
          Thin (4px)
        </p>
        <ScrollArea
          type="always"
          scrollbarSize={4}
          maxHeight={150}
          style={{
            border: '1px solid var(--tao-color-border-secondary)',
            borderRadius: 6,
          }}
        >
          <div style={{ padding: 16 }}>
            {items.slice(0, 30).map((item) => (
              <p
                key={item}
                style={{
                  margin: '0 0 8px',
                  color: 'var(--tao-color-text-secondary)',
                }}
              >
                {item}
              </p>
            ))}
          </div>
        </ScrollArea>
      </div>
      <div>
        <p
          style={{
            fontSize: 13,
            color: 'var(--tao-color-text-secondary)',
            marginBottom: 8,
          }}
        >
          Thick (10px)
        </p>
        <ScrollArea
          type="always"
          scrollbarSize={10}
          maxHeight={150}
          style={{
            border: '1px solid var(--tao-color-border-secondary)',
            borderRadius: 6,
          }}
        >
          <div style={{ padding: 16 }}>
            {items.slice(0, 30).map((item) => (
              <p
                key={item}
                style={{
                  margin: '0 0 8px',
                  color: 'var(--tao-color-text-secondary)',
                }}
              >
                {item}
              </p>
            ))}
          </div>
        </ScrollArea>
      </div>
    </Stack>
  );
}
```

```tsx preview
export default function ScrollAreaHorizontalShadow() {

      direction="horizontal"

      style={{
        border: '1px solid var(--tao-color-border-secondary)',
        borderRadius: 6,
      }}
    >
      <div
        style={{ display: 'flex', gap: 8, padding: 16, width: 'max-content' }}
      >
        {items.slice(0, 30).map((item) => (
          <div
            key={item}
            style={{
              flexShrink: 0,
              width: 100,
              height: 60,
              display: 'flex',
              alignItems: 'center',
              justifyContent: 'center',
              background: 'var(--tao-color-fill-quaternary)',
              borderRadius: 6,
              fontSize: 13,
              color: 'var(--tao-color-text-secondary)',
            }}
          >
            {item}
          </div>
        ))}
      </div>
    </ScrollArea>
  );
}
```
