统一排列表单中的提交、取消与次要操作。

## 何时使用

表单底部需要稳定、可预测的操作区域时使用 FormActions。

**推荐**

- 主操作保持唯一并放在一致位置。
- 取消与破坏性操作使用正确语义层级。

**避免**

- 不要把无关操作混入表单操作区。

### 完整表单组合

组合布局、字段与操作区，用原生提交展示保存结果。

```tsx preview
import { useState } from 'react';
import {
  FormLayout,
  FormSection,
  FormField,
  FormActions,
  Input,
  Textarea,
  Button,
} from '@rockshin/tao-ui';
export default function Example() {
  const [saved, setSaved] = useState('');
  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        setSaved(String(new FormData(e.currentTarget).get('name')));
      }}
      onReset={() => setSaved('')}
    >
      <FormLayout>
        <FormSection title="Profile" description="Public workspace information">
          <FormField label="Display name" required>
            <Input name="name" required defaultValue="Alex" />
          </FormField>
          <FormField label="Bio" description="A short introduction">
            <Textarea name="bio" autoSize />
          </FormField>
        </FormSection>
        <FormActions>
          <Button type="reset">Reset</Button>
          <Button type="submit" variant="primary">
            Save
          </Button>
        </FormActions>
        <output aria-live="polite">
          {saved ? `Saved ${saved}` : 'No changes saved'}
        </output>
      </FormLayout>
    </form>
  );
}
```

</section>

### 对齐与换行

通过 root 样式设置对齐，窄屏保留自然换行。

```tsx preview
import { FormActions, Button } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <FormActions
      styles={{ root: { justifyContent: 'space-between', flexWrap: 'wrap' } }}
    >
      <Button>Back</Button>
      <Button variant="primary">Continue</Button>
    </FormActions>
  );
}
```

### 操作等待状态

等待时统一禁用操作并显示加载；按钮可结束本地演示状态。

```tsx preview
import { useState } from 'react';
import { FormActions, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [pending, setPending] = useState(false);
  return (
    <Stack direction="vertical">
      <FormActions>
        <Button disabled={pending}>Cancel</Button>
        <Button loading={pending} onClick={() => setPending(true)}>
          Save
        </Button>
      </FormActions>
      {pending && (
        <Button onClick={() => setPending(false)}>
          Finish simulated request
        </Button>
      )}
    </Stack>
  );
}
```
