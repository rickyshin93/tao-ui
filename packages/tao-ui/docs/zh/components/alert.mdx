用于展示带有明确语义状态的重要上下文反馈信息。

## 何时使用

页面需要持续展示某个状态、风险或操作结果时使用 Alert；短暂通知应使用 Sonner。

**推荐**

- 根据消息严重程度选择对应的语义类型。
- 标题保持简短，将补充信息放入说明。
- 需要快速扫读时开启状态图标。

**避免**

- 避免在同一视图堆叠大量 Alert。
- 不要用 Alert 承载短暂反馈，改用 toast。

### 可关闭提示与操作

```tsx preview
import { Alert, Button, Stack } from '@rockshin/tao-ui';

function ActionAlerts() {
  return (
    <Stack gap="md">
      <Alert type="info" title="Closable message" closable showIcon />
      <Alert
        type="warning"
        title="Payment method expires soon"
        description="Update it before the next billing date."
        showIcon
        action={
          <Button size="small" variant="secondary">
            Update
          </Button>
        }
      />
      <Alert
        type="error"
        title="Connection lost"
        action={<Button size="small">Retry</Button>}
        closable
        showIcon
      />
    </Stack>
  );
}

export default ActionAlerts;
```

### 状态图标

`showIcon` 为成功、信息、警告和错误提供对应的语义图标。


### 行内操作

通过 `action` 放置与提示相关的操作，操作结果应在应用中明确反馈。

```tsx preview
import { useState } from 'react';
import { Alert, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [updated, setUpdated] = useState(false);
  const [retried, setRetried] = useState(false);
  return (
    <Stack>
      <Alert
        type={updated ? 'success' : 'info'}
        title={updated ? 'Demo update applied' : 'New version available'}
        showIcon
        action={
          <Button
            size="small"
            disabled={updated}
            onClick={() => setUpdated(true)}
          >
            Update
          </Button>
        }
      />
      <Alert
        type={retried ? 'success' : 'error'}
        title={retried ? 'Demo retry completed' : 'Request failed'}
        description="These actions update local example state."
        showIcon
        action={
          <Button
            size="small"
            disabled={retried}
            onClick={() => setRetried(true)}
          >
            Retry
          </Button>
        }
      />
    </Stack>
  );
}
```
