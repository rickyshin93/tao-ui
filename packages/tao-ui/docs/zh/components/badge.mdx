展示计数、紧凑状态标记与缎带。

组件采用 tao-ui 原生实现，公共 API 对齐 Ant Design 6.7.0。外观、主题 token 与 Semantic DOM 定制遵循 tao-ui，主题通过 `TaoProvider` 配置。

Badge 遵循 6.7.0 计数与状态 API；颜色和 Ribbon 使用 tao-ui token，计数变化直接更新。

## 何时使用

把计数关联到对应控件，状态信息同时提供文字。

```tsx preview
import { Avatar, Badge } from "@rockshin/tao-ui";

export default function Example() {
  return (
    <div
      style={{

        alignItems: "center",
        flexWrap: "wrap",
```

### 改变计数

```tsx preview
import { useState } from "react";
import { Badge, Button } from "@rockshin/tao-ui";

export default function Example() {
  const [count, setCount] = useState(5);
  return (
    <div
      style={{
        display: "flex",
        gap: 16,
        alignItems: "center",
        flexWrap: "wrap",
      }}
    >
      <Badge count={count} showZero />
      <Button onClick={() => setCount(Math.max(0, count - 1))}>−</Button>
      <Button onClick={() => setCount(count + 1)}>+</Button>
    </div>
  );
}
```

</section>
