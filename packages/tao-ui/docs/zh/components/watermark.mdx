在内容与继承的弹层上重复绘制文字或图片水印。

组件采用 tao-ui 原生实现，公共 API 对齐 Ant Design 6.7.0。外观、主题 token 与 Semantic DOM 定制遵循 tao-ui，主题通过 `TaoProvider` 配置。

Canvas 绘制遵循 6.7.0 content/font/gap/offset API；Modal 与 Drawer 默认继承，inherit=false 关闭门户继承；被移除或篡改的覆盖层会恢复。

## 何时使用

用于标记所有者、工作区或资料类别，同时保持正文可读。

### 继承到 Modal 与 Drawer

```tsx preview="iframe-follow"
import { useState } from "react";
import { Button, Drawer, Modal, Watermark } from "@rockshin/tao-ui";

export default function Example() {
  const [panel, setPanel] = useState("");
  return (
    <Watermark content="Private">
      <div style={{ minHeight: 220, padding: 20 }}>
        <Button onClick={() => setPanel("modal")}>Open modal</Button>{" "}
        <Button onClick={() => setPanel("drawer")}>Open drawer</Button>
        <Modal
          open={panel === "modal"}
          onClose={() => setPanel("")}
          title="Marked modal"
          footer={null}
        >
          <div style={{ height: 150 }}>
            This portaled panel inherits the watermark.
          </div>
        </Modal>
        <Drawer
          open={panel === "drawer"}
          onClose={() => setPanel("")}
          title="Marked drawer"
        >
          <p>The drawer inherits the same watermark.</p>
        </Drawer>
      </div>
    </Watermark>
  );
}
```

</section>

### 关闭门户继承

```tsx preview="iframe-follow"
import { useState } from "react";
import { Button, Modal, Watermark } from "@rockshin/tao-ui";

export default function Example() {
  const [open, setOpen] = useState(false);
  return (
    <Watermark content="Page only" inherit={false}>
      <div style={{ minHeight: 220, padding: 20 }}>
        <Button onClick={() => setOpen(true)}>Open unmarked modal</Button>
        <Modal
          open={open}
          onClose={() => setOpen(false)}
          title="No inherited mark"
          footer={null}
        >
          Only the containing page has a watermark.
        </Modal>
      </div>
    </Watermark>
  );
}
```
