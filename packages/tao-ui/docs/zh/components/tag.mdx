使用紧凑标签展示类别、状态或可选择筛选条件。

## 何时使用

需要在较小空间表达状态、分类或轻量选择时使用 Tag。

**推荐**

- 语义颜色保持一致。
- 可关闭与可选择标签提供明确交互反馈。

**避免**

- 不要用大量彩色 Tag 制造视觉噪音。

### 自定义颜色与可关闭标签

```tsx preview
import { useState } from 'react';
import { Stack, Tag } from '@rockshin/tao-ui';

function CustomTags() {
  const [feedback, setFeedback] = useState('');
  return (
    <>
      <Stack direction="horizontal" gap="sm">
        <Tag color="#245b57" variant="solid">
          Custom teal
        </Tag>
        <Tag color="#8a5a21" variant="outlined">
          Custom ochre
        </Tag>
        {feedback !== 'closed' && (
          <Tag color="primary" closeIcon onClose={() => setFeedback('closed')}>
            Closable
          </Tag>
        )}
        <Tag disabled color="primary" variant="solid">
          Disabled
        </Tag>
      </Stack>
      <output
        aria-live="polite"
        style={{
          display: 'block',
          marginTop: 12,
          whiteSpace: 'pre-wrap',
          overflowWrap: 'anywhere',
        }}
      >
        {feedback}
      </output>
    </>
  );
}

export default CustomTags;
```

### 可选择标签

```tsx preview
import { CheckableTag, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

function CheckableTags() {
  const [selected, setSelected] = useState(['Design']);

  return (
    <Stack direction="horizontal" gap="sm">
      {['Design', 'Engineering', 'Research'].map((label) => (
        <CheckableTag
          key={label}
          checked={selected.includes(label)}
          onChange={(checked) =>
            setSelected((items) =>
              checked
                ? [...items, label]
                : items.filter((item) => item !== label),
            )
          }
        >
          {label}
        </CheckableTag>
      ))}
    </Stack>
  );
}

export default CheckableTags;
```

### 可选择标签

通过 `checked` 与变更回调实现轻量的分类筛选。

```tsx preview
import { CheckableTag, Stack } from '@rockshin/tao-ui';

import { useState } from 'react';

export default function TagCheckable() {
  function Demo() {
    const [selected, setSelected] = useState<string[]>(['react']);
    const options = ['react', 'vue', 'angular', 'svelte', 'solid'];
    return (
      <Stack direction="horizontal" gap="sm">
        {options.map((opt) => (
          <CheckableTag
            key={opt}
            checked={selected.includes(opt)}
            onChange={(checked) =>
              setSelected((prev) =>
                checked ? [...prev, opt] : prev.filter((x) => x !== opt),
              )
            }
          >
            {opt}
          </CheckableTag>
        ))}
      </Stack>
    );
  }
  return <Demo />;
}
```

### 不可操作标签

禁用时停止选择或移除操作，保留标签内容供查看。

```tsx preview
import { CheckableTag, Stack, Tag } from '@rockshin/tao-ui';

export default function TagDisabled() {
  return (
    <Stack direction="horizontal" gap="sm">
      <Tag disabled>Disabled</Tag>
      <Tag disabled color="primary" variant="solid">
        Disabled Solid
      </Tag>
      <Tag disabled onClose={() => {}}>
        Can't Close
      </Tag>
      <CheckableTag disabled>Can't Check</CheckableTag>
    </Stack>
  );
}
```
