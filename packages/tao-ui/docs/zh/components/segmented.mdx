从紧凑选项中选择单个视图或模式。

组件采用 tao-ui 原生实现，公共 API 对齐 Ant Design 6.7.0。外观、主题 token 与 Semantic DOM 定制遵循 tao-ui，主题通过 `TaoProvider` 配置。

6.7.0 value/options API 使用原生单选控件与 tao-ui 动效实现；尺寸继承 TaoProvider，减弱动态效果时关闭移动高亮。

## 何时使用

适合少量紧密相关的选项，原生单选控件支持表单提交与键盘选择。

### 受控选择

```tsx preview
import { useState } from "react";
import { Segmented } from "@rockshin/tao-ui";

export default function Example() {
  const [view, setView] = useState("List");
  return (
    <div>
      <Segmented<string>
        options={["List", "Board", "Calendar"]}
        value={view}
        onChange={setView}
      />
      <p>Current view: {view}</p>
    </div>
  );
}
```

### 提交原生表单

```tsx preview
import { useState } from "react";
import { Button, Segmented } from "@rockshin/tao-ui";

export default function Example() {
  const [submitted, setSubmitted] = useState("");
  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        setSubmitted(String(new FormData(event.currentTarget).get("period")));
      }}
    >
      <Segmented
        name="period"
        options={["Day", "Week", "Month"]}
        defaultValue="Week"
      />
      <Button type="submit" style={{ marginLeft: 12 }}>
        Apply
      </Button>
      <p>Submitted: {submitted || "—"}</p>
    </form>
  );
}
```
