在悬停或键盘聚焦时展示简短补充说明。

## 何时使用

图标、缩写或控件需要一行辅助解释时使用 Tooltip。

**推荐**

- 内容保持简短。
- 确保键盘聚焦也能触发。

**避免**

- 关键说明或交互内容不要只放在 Tooltip 中。

### 受控提示

用 open 与 onOpenChange 同步可见状态。

```tsx preview
import { useState } from 'react';
import { Button, Stack, Tooltip } from '@rockshin/tao-ui';
export default function Example() {
  const [open, setOpen] = useState(false);
  return (
    <Stack direction="horizontal">
      <Button onClick={() => setOpen(!open)}>
        {open ? 'Hide hint' : 'Show hint'}
      </Button>
      <Tooltip open={open} onOpenChange={setOpen} title="Controlled hint">
        <Button>Hint target</Button>
      </Tooltip>
    </Stack>
  );
}
```

</section>

### 悬停延迟

延迟以秒为单位，键盘焦点不等待悬停延迟。

```tsx preview
import { Tooltip, Button } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <Tooltip
      title="Wait 0.6 seconds on hover"
      mouseEnterDelay={0.6}
      mouseLeaveDelay={0.2}
    >
      <Button>Hover or focus</Button>
    </Tooltip>
  );
}
```

</section>

### 条件提示

title 为空时禁用提示，适合仅在需要解释时显示。

```tsx preview
import { useState } from 'react';
import { Tooltip, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [enabled, setEnabled] = useState(true);
  return (
    <Stack direction="vertical">
      <Button onClick={() => setEnabled(!enabled)}>
        {enabled ? 'Disable hint' : 'Enable hint'}
      </Button>
      <Tooltip title={enabled ? 'Additional information' : null}>
        <Button>Hint target</Button>
      </Tooltip>
    </Stack>
  );
}
```
