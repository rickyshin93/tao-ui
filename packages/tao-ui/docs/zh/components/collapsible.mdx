以无障碍方式展开或收起一段内容区域。

## 何时使用

需要隐藏次要细节，同时保持页面结构轻量时使用 Collapsible。

**推荐**

- 触发器标签应说明被隐藏的内容。
- 需要与其他界面状态协调时使用受控模式。

**避免**

- 不要把必填表单项隐藏在没有明确提示的折叠区域中。

### 基础用法

```tsx preview
import { Collapsible } from '@rockshin/tao-ui';

function CollapsibleExample() {
  return (
    <Collapsible defaultOpen>

      <Collapsible.Content>

          The content remains mounted while its accessible disclosure state

        </p>
      </Collapsible.Content>
    </Collapsible>
  );
}

export default CollapsibleExample;
```

### 受控状态

```tsx preview
import { Button, Collapsible, Stack } from '@rockshin/tao-ui';
import { useState } from 'react';

function ControlledCollapsible() {
  const [open, setOpen] = useState(false);

  return (
    <Stack gap="sm">
      <Button variant="secondary" onClick={() => setOpen((value) => !value)}>
        {open ? 'Hide' : 'Show'} release notes
      </Button>
      <Collapsible open={open} onOpenChange={setOpen}>
        <Collapsible.Content>
          Version 0.0.25 improves semantic DOM customization.
        </Collapsible.Content>
      </Collapsible>
    </Stack>
  );
}

export default ControlledCollapsible;
```

### 受控展开

通过 `open` 与 `onOpenChange` 同步外部按钮和折叠面板的状态。

```tsx preview
import { Collapsible } from '@rockshin/tao-ui';

import { useState } from 'react';

const triggerStyle: React.CSSProperties = {
  padding: '8px 12px',
  border: '1px solid var(--tao-color-border)',
  borderRadius: 'var(--tao-radius-md)',
  background: 'var(--tao-color-bg-container)',
};

const panelStyle: React.CSSProperties = {
  marginTop: 8,
  padding: 12,
  border: '1px solid var(--tao-color-border-secondary)',
  borderRadius: 'var(--tao-radius-md)',
};

export default function CollapsibleControlled() {
  const [open, setOpen] = useState(false);
  return (
    <div style={{ width: 320 }}>
      <div style={{ marginBottom: 8 }}>State: {open ? 'open' : 'closed'}</div>
      <Collapsible open={open} onOpenChange={setOpen}>
        <Collapsible.Trigger style={triggerStyle}>
          {open ? 'Hide' : 'Show'}
        </Collapsible.Trigger>
        <Collapsible.Content>
          <div style={panelStyle}>Controlled from parent state.</div>
        </Collapsible.Content>
      </Collapsible>
    </div>
  );
}
```

</section>

### 禁止切换

`disabled` 阻止用户切换；可保留已有展开状态供阅读。

```tsx preview
import { Collapsible } from '@rockshin/tao-ui';

const triggerStyle: React.CSSProperties = {
  padding: '8px 12px',
  border: '1px solid var(--tao-color-border)',
  borderRadius: 'var(--tao-radius-md)',
  background: 'var(--tao-color-bg-container)',
};

const panelStyle: React.CSSProperties = {
  marginTop: 8,
  padding: 12,
  border: '1px solid var(--tao-color-border-secondary)',
  borderRadius: 'var(--tao-radius-md)',
};

export default function CollapsibleDisabled() {
  return (
    <Collapsible disabled>
      <Collapsible.Trigger style={triggerStyle}>
        Can't toggle
      </Collapsible.Trigger>
      <Collapsible.Content>
        <div style={panelStyle}>You should never see this.</div>
      </Collapsible.Content>
    </Collapsible>
  );
}
```

</section>

### 自定义触发内容

触发区可以组合标题、摘要和方向提示；整个区域仍是同一个可操作入口。

```tsx preview
import { Collapsible } from '@rockshin/tao-ui';

const panelStyle: React.CSSProperties = {
  marginTop: 8,
  padding: 12,
  border: '1px solid var(--tao-color-border-secondary)',
  borderRadius: 'var(--tao-radius-md)',
};

function Chevron() {
  return (
    <span data-tao-collapsible-chevron="">
      <svg
        width="16"
        height="16"
        viewBox="0 0 24 24"
        fill="none"
        stroke="currentColor"
        strokeWidth="2"
        strokeLinecap="round"
        strokeLinejoin="round"
        aria-hidden="true"
        focusable="false"
      >
        <path d="m6 9 6 6 6-6" />
      </svg>
    </span>
  );
}

export default function CollapsibleWithChevron() {
  return (
    <Collapsible defaultOpen>
      <Collapsible.Trigger asChild>
        <button
          type="button"
          style={{
            display: 'inline-flex',
            alignItems: 'center',
            gap: 8,
            padding: '8px 12px',
            border: '1px solid var(--tao-color-border)',
            borderRadius: 'var(--tao-radius-md)',
            background: 'var(--tao-color-bg-container)',
            cursor: 'pointer',
            font: 'inherit',
            color: 'var(--tao-color-text)',
          }}
        >
          <span style={{ fontWeight: 500 }}>Order #4189</span>
          <Chevron />
        </button>
      </Collapsible.Trigger>
      <Collapsible.Content>
        <div style={panelStyle}>
          <div>Status: Shipped</div>
          <div>Carrier: Tao Express</div>
        </div>
      </Collapsible.Content>
    </Collapsible>
  );
}
```

</section>
