立即切换一个布尔设置，并展示当前开关状态。

## 何时使用

设置可立即生效且不需要额外提交时使用 Switch。

**推荐**

- 标签描述开启后的状态。
- 异步切换期间使用 loading。

**避免**

- 需要提交确认或选择多个值时不要使用 Switch。

### 基础用法

```tsx preview
import { Stack, Switch } from '@rockshin/tao-ui';
import { useState } from 'react';

function SwitchExample() {
  const [enabled, setEnabled] = useState(true);

  return (
    <Stack direction="horizontal" gap="lg" align="center">
      <Switch checked={enabled} onChange={setEnabled} />
      <Switch checked loading />
      <Switch disabled />
    </Stack>
  );
}

export default SwitchExample;
```

### 受控开关

onChange 返回布尔值，可直接与设置状态同步。

```tsx preview
import { useState } from 'react';
import { Switch, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [enabled, setEnabled] = useState(true);
  return (
    <Stack direction="vertical">
      <Switch
        aria-label="Notifications"
        checked={enabled}
        onChange={setEnabled}
      />
      <output>
        {enabled ? 'Notifications enabled' : 'Notifications disabled'}
      </output>
    </Stack>
  );
}
```

### 加载期间禁止重复切换

使用独立按钮切换 loading，观察开关的等待状态。

```tsx preview
import { useState } from 'react';
import { Switch, Button, Stack } from '@rockshin/tao-ui';
export default function Example() {
  const [loading, setLoading] = useState(false);
  return (
    <Stack direction="vertical">
      <Switch aria-label="Sync" loading={loading} defaultChecked />
      <Button onClick={() => setLoading(!loading)}>
        {loading ? 'Finish loading' : 'Start loading'}
      </Button>
    </Stack>
  );
}
```

### 状态文字与尺寸

        defaultChecked

        size="small"
        aria-label="Compact access"
        checkedChildren="On"
        unCheckedChildren="Off"
        defaultChecked
      />
      <Switch
        aria-label="Locked access"
        checkedChildren="On"
        unCheckedChildren="Off"
        defaultChecked
        disabled
      />

}

### 共享尺寸与禁用

多个开关可继承配置，局部 disabled 可以覆盖。

```tsx preview
import { Switch, TaoProvider, Stack } from '@rockshin/tao-ui';
export default function Example() {
  return (
    <TaoProvider size="small" disabled>
      <Stack>
        <Switch aria-label="Inherited disabled" defaultChecked />
        <Switch aria-label="Enabled override" disabled={false} />
      </Stack>
    </TaoProvider>
  );
}
```
