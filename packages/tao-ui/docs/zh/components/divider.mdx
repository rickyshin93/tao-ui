将内容分为清晰的区块或行内分组。

组件采用 tao-ui 原生实现，公共 API 对齐 Ant Design 6.7.0。外观、主题 token 与 Semantic DOM 定制遵循 tao-ui，主题通过 `TaoProvider` 配置。

使用 titlePlacement 控制标题位置，orientation 控制方向；默认尺寸继承 TaoProvider。

## 何时使用

用于区分相邻内容中的不同区块。

### 区块与标题

```tsx preview
import { Divider } from "@rockshin/tao-ui";

export default function Example() {
  return (

      <Divider>Activity</Divider>
      <p>Recent changes and updates.</p>
      <Divider />
      <p>End of report.</p>
    </div>
  );
}
```
