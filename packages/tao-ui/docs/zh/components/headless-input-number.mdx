提供数值输入的解析、格式化与约束逻辑，不绑定产品视觉。

## 何时使用

需要完全自定义数值输入外观，同时复用可靠的数值行为时使用 HeadlessInputNumber。

**推荐**

- 明确配置小数位与分隔符。
- 显示值与提交值保持可预测转换。

**避免**

- 不需要自定义视觉时优先使用 InputNumber。

## 基础用法

```tsx preview
import { HeadlessInputNumber } from '@rockshin/tao-ui';
import { useState } from 'react';

function HeadlessInputNumberExample() {
  const [value, setValue] = useState('');

  return (
    <HeadlessInputNumber
      value={value}
      onChange={setValue}
      prefix="$"
      decimalPlaces={2}
      thousandsSeparator=","
      placeholder="Enter amount"
    />
  );
}

export default HeadlessInputNumberExample;
```

## 格式化与前后缀

```tsx preview
import { HeadlessInputNumber, Stack } from '@rockshin/tao-ui';

function HeadlessNumberFormats() {
  return (
    <Stack gap="md">
      <HeadlessInputNumber
        defaultValue="1234567.5"
        prefix="$"
        suffix="USD"
        decimalPlaces={2}
        thousandsSeparator=","
      />
      <HeadlessInputNumber
        defaultValue="0.275"
        isPercentage
        suffix="%"
        decimalPlaces={1}
      />
    </Stack>
  );
}

export default HeadlessNumberFormats;
```

## 本地化分隔符与范围

```tsx preview
import { HeadlessInputNumber, Stack } from '@rockshin/tao-ui';

function HeadlessNumberConstraints() {
  return (
    <Stack gap="md">
      <HeadlessInputNumber
        defaultValue="1234.5"
        thousandsSeparator="."
        decimalSeparator=","
        decimalPlaces={2}
      />
      <HeadlessInputNumber defaultValue="50" min={0} max={100} suffix=" units" />
    </Stack>
  );
}

export default HeadlessNumberConstraints;
```
