突出展示数值、格式化指标与计时。

组件采用 tao-ui 原生实现，公共 API 对齐 Ant Design 6.7.0。外观、主题 token 与 Semantic DOM 定制遵循 tao-ui，主题通过 `TaoProvider` 配置。

数字字符串保留大数精度；precision 截取小数位。Timer 支持倒计时与正计时，并保留旧 Countdown 别名。

## 何时使用

提供清晰标题与单位，使数值不依赖额外上下文也能理解。

### 自定义格式与数值渲染

export default function Example() {
  return (
    <Statistic
      title="Storage used"
      value={1536}
      formatter={(value) => `${(Number(value) / 1024).toFixed(1)} GB`}

### 倒计时与完成反馈

```tsx preview
import { useState } from "react";
import { Button, Statistic } from "@rockshin/tao-ui";

export default function Example() {
  const [deadline, setDeadline] = useState(() => Date.now() + 10000);
  const [finished, setFinished] = useState(false);
  return (
    <div>
      <Statistic.Timer
        type="countdown"
        title="Time remaining"
        value={deadline}
        format="mm:ss"
        onFinish={() => setFinished(true)}
      />
      <p aria-live="polite">{finished ? "Finished" : "Running"}</p>
      <Button
        onClick={() => {
          setDeadline(Date.now() + 10000);
          setFinished(false);
        }}
      >
        Restart 10 seconds
      </Button>
    </div>
  );
}
```

</section>

## 地区格式

地区分组、小数符号和数字字符继承 `TaoProvider.locale.numberLocale`，也可用组件 `locale="fr-FR"` 覆盖。显式分隔符和自定义 formatter 优先；数字输入在本地化显示的同时保留规范 ASCII 字符串及精度。
