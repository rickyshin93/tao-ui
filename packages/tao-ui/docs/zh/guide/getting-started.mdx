React 和 React DOM 最低需要 18.2，同时兼容 React 19，两者的 peer dependency 范围均为 `^18.2.0 || ^19.0.0`。日期组件使用的 `dayjs` 是普通依赖，会自动安装。使用你偏好的包管理器安装 tao-ui。

<PackageManagerTabs command="install @rockshin/tao-ui" />

## 添加 Provider

在应用根部包裹一次 `TaoProvider`。组件会继承尺寸、禁用状态与主题模式等设置。

```tsx
import { Button, TaoProvider } from '@rockshin/tao-ui';

export default function App() {
  return (
    <TaoProvider size="medium">
      <Button>继续</Button>
    </TaoProvider>
  );
}
```

## 按组件引入

按组件入口引入时，只加载对应组件及其依赖的样式，并自动包含公共主题样式，无需额外导入 CSS。现有根入口继续可用，会包含全部组件样式。

```tsx
import { Button, type ButtonProps } from '@rockshin/tao-ui/button';
import { TaoProvider } from '@rockshin/tao-ui/provider';
```

入口使用短横线命名，例如 `/input-number`、`/range-picker`、`/form-layout`。同组导出共用入口：`CheckboxGroup` 使用 `/checkbox`，`HeadlessInputNumber` 使用 `/number-input`。

## 控制字段值

Input、Textarea、InputNumber、Select、DatePicker 和 RangePicker 中，显式传入 `value={undefined}` 表示受控空值。非受控字段应省略 `value`，使用 `defaultValue` 设置初始值。表单中可通过 `form.setFieldsValue({ field: undefined })` 清空字段，无需重新挂载控件。

## 使用深色模式

在 Provider 上设置主题模式。通过 Portal 渲染的组件也会继承同一主题。

```tsx
<TaoProvider theme={{ mode: 'dark' }}>
  <App />
</TaoProvider>
```
