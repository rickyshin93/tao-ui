# Rounded Essentials · 设计与语义范围

本 React 包共 554 枚图标：原 200 枚通用、已确认的保险 130 枚，以及新请求范围内的通用 224 枚候选。原批准 330 枚的原始 SVG、canonical 几何、名称和组件映射保持不变，包括用户指定的原版人物＋爱心 beneficiary。

## 视觉规则

24×24 viewBox、1.8 单位 currentColor 描边、圆线帽与圆连接；容器使用克制的小圆角。优先一个主轮廓或动作，最多一个必要的语义修饰。避免在 16px 下依靠细密装饰、徽章叠加和微型场景表达含义。

新增通用范围依据主流图标目录中的常见界面概念，并由导航、表单、文件、文字编辑、布局、数据图表、身份安全、通信、媒体、连接、商业地点、时间任务、无障碍和开发 AI 的具体使用场景选取。优先级属于设计判断，不是实测市场使用排名。不复制第三方 SVG 路径、源代码或品牌图形。

## 去重与连续性

已有 undo/redo、filter、grid 等语义直接重用。square → checkbox、circle-dot/record → radio-button-selected 等常见别名作为目录检索索引，不新增重复导出。car → insurance-auto、volume-high → volume 也重用既有图形；别名保存于 manifest 顶层，原批准图标 tags 不改写。

冻结文件和候选完整性 hash 分开记录。原保险简化修订已经用户确认；新 224 枚仍是候选，范围授权不能替代最终设计确认。

## 可访问性和语义限制

按钮、导航和业务状态应配可见文字。不要仅靠图标表示真实保障承诺、核保结论、资格决定、理赔结果或支付状态。图形使用同一简洁词汇是合理的，不为追求差异堆砌细节。

React 组件默认装饰性；title 或显式 ARIA 名称提供可访问标签。16px、20px 和 24px 设计预览由独立 SVG 资产包提供，本包没有另外宣称像素提示版 16px 母版或屏幕阅读器实机覆盖。

## 重现

`data/icons.json` 为 React canonical 几何；生成器将其转成独立 TSX，Rslib 输出 ESM 与声明。`svg/` 保存所有原始资产。新通用导入器与候选原始 JSON 同包提供，分类与完整目录见 GENERIC-COVERAGE.md，测试契约见 HARNESS.md。
